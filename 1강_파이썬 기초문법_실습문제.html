정답 보기
python --version   # 또는  python -V
→ Python 3.13.1

· 인터프리터 언어 예: Python (또는 JavaScript)
· 컴파일러 언어 예: C (또는 C++, Java)

🤖 AI 실습 1-2. 오류 메시지 해결사

아래 오류가 났다고 가정하고, ChatGPT가 정확한 해결법을 주도록 프롬프트를 작성하세요. 실제 설치 중 오류가 났다면 그 메시지를 그대로 붙여넣어 물어보세요.

'python'은(는) 내부 또는 외부 명령, 실행할 수 있는 프로그램, 또는 배치 파일이 아닙니다.
예시 프롬프트 · 핵심 보기
나는 파이썬 완전 초보야. 윈도우 명령 프롬프트에서 python 을 입력하니 "'python'은(는) 내부 또는 외부 명령... 이 아닙니다"라는 오류가 나와. 원인이 뭐고, 재설치 없이 고칠 수 있는 방법과 재설치해야 하는 경우를 나눠서 알려 줘.

핵심 원인은 설치할 때 “Add python.exe to PATH”를 체크하지 않은 것입니다. AI 답을 받은 뒤 실제로 PATH 설정을 확인하세요. — AI 답은 항상 직접 실행해 검증!

파이썬 IDLE와 기초 문법 · 변수(Variable)

✏️ 실습문제

실습 1-1. 개발 환경 세팅

VS Code를 설치하고 Python·Korean 확장을 적용한 뒤, 작업 폴더를 열어 test.py를 만들어 오늘 날짜와 이름을 출력하고 실행하세요.
정답 보기
print("2026-07-25 / 홍길동")

확장 설치 → 폴더 열기 → 파일 작성 → Ctrl + F5 순서로 진행하면 됩니다.

🤖 AI 실습 1-2. 터미널 오류, AI에게 통역받기

실행 중 터미널에 빨간 오류 메시지가 나오면 전체를 그대로 복사해 ChatGPT에 붙여넣고 원인·해결법을 물어보세요. 오류가 없다면, 아래 상황을 가정해 프롬프트를 작성해 보세요.

“python : 용어가 cmdlet, 함수... 이름으로 인식되지 않습니다”
예시 프롬프트 · 핵심 보기
VS Code 터미널에서 파이썬 파일을 실행하니 "python : 용어가 cmdlet, 함수, 스크립트 파일 또는 실행할 수 있는 프로그램 이름으로 인식되지 않습니다"라는 오류가 나. 초보자용으로 원인과 해결 방법을 단계별로 알려 줘.

보통 파이썬이 PATH에 없거나 python 대신 py를 써야 하는 경우입니다. AI 답을 실제 터미널에서 실행해 확인하세요.

✏️ 실습문제

실습 2-1. 내 소개 출력하기

IDLE 에디터에서 새 파일을 만들어, print()로 내 이름과 좋아하는 것을 두 줄로 출력하는 프로그램을 작성하고 intro.py로 저장해 F5로 실행하세요. 코드 맨 위에는 한 줄 주석으로 프로그램 설명을 넣으세요.
정답 보기
# 나를 소개하는 프로그램
print("제 이름은 홍길동입니다.")
print("저는 파이썬 공부를 좋아합니다.")
제 이름은 홍길동입니다. 저는 파이썬 공부를 좋아합니다.

🤖 AI 실습 2-2. AI에게 코드 검토받기

실습 2-1을 스스로 작성한 뒤, 내 코드를 ChatGPT에 붙여넣고 “틀린 곳이나 더 좋게 고칠 부분이 있는지” 검토를 요청하세요. AI가 제안한 내용을 실제로 실행해 결과가 같은지 확인하세요.
예시 프롬프트 보기
파이썬 초보인데 아래 코드를 작성했어. 오류가 없는지, 초보자가 배우기에 더 좋은 방식이 있는지 검토해 줘. 문법 설명도 곁들여 줘. # 나를 소개하는 프로그램 print("제 이름은 홍길동입니다.") print("저는 파이썬 공부를 좋아합니다.")

AI가 f-string이나 \n 같은 방법을 제안할 수 있습니다. 새 문법이 나오면 “그게 뭐야?”라고 다시 물어보며 확장 학습하세요.

✏️ 실습문제

실습 3-1. 프로필 변수 만들기

이름, 나이, 사는 도시를 각각 변수 name, age, city에 저장하고, print()로 “OOO님은 OO살이고 OO에 삽니다.” 형태로 한 줄 출력하세요.
정답 보기
name = "김파이"
age = 25
city = "서울"
print(name, "님은", age, "살이고", city, "에 삽니다.")
김파이 님은 25 살이고 서울 에 삽니다.

실습 3-2. 잘못된 변수 이름 찾기

다음 중 변수 이름으로 쓸 수 없는 것을 모두 고르고, 이유를 설명하세요.
① user_id   ② 2age   ③ my age   ④ for   ⑤ total3
정답 보기

쓸 수 없는 것: ② ③ ④

  • ② 2age — 숫자로 시작할 수 없음
  • ③ my age — 이름 중간에 공백이 있음
  • ④ for — 예약어라서 사용 불가

🤖 AI 실습 3-3. AI 답을 검증하기

ChatGPT에게 “파이썬 변수 이름으로 쓸 수 없는 예시 5개와 그 이유”를 물어보세요. 그리고 AI가 준 예시를 IDLE에서 실제로 변수로 만들어 보며 정말 오류가 나는지 직접 확인하세요.
검증 방법 보기

예: AI가 2age를 “불가”라고 했다면 IDLE 쉘에 직접 입력해 확인합니다.

>>> 2age = 10
SyntaxError: invalid syntax   # AI 말이 맞음 → 검증 완료

AI가 틀리는 경우도 있으니, 애매한 예시는 이렇게 직접 실행해 확인하는 습관이 중요합니다.

자료형(Data Type) · 컴퓨터의 데이터 표현

✏️ 실습문제

실습 4-1. 자료형 맞히기

다음 값들의 자료형을 예측해 적고, type()으로 확인하세요.
2026, 98.6, "010-1234", False
정답 보기

2026 → int,   98.6 → float,   "010-1234" → str,   False → bool

print(type(2026), type(98.6), type("010-1234"), type(False))
→ <class 'int'> <class 'float'> <class 'str'> <class 'bool'>
주의 "010-1234"는 숫자처럼 보여도 따옴표로 감쌌으니 문자열(str)입니다.

🤖 AI 실습 4-2. AI로 퀴즈 만들어 풀기

ChatGPT에게 “자료형 맞히기 퀴즈 5문제를 정답은 숨기고 내 줘”라고 요청해, 스스로 풀어보세요. 다 풀면 정답을 요청해 채점하고, 틀린 문제는 이유를 물어보세요.
예시 프롬프트 보기
파이썬 자료형(int, float, str, bool) 구분 연습문제 5개를 만들어 줘. 각 문제는 값 하나를 보여주고 자료형을 맞히는 형식이야. 정답은 아직 알려주지 말고, 내가 답한 뒤에 채점해 줘.

AI를 출제자로 활용하면 무한히 연습할 수 있습니다. 채점 후 type()으로 최종 검증하세요.

✏️ 실습문제

실습 5-1. 손으로 2진수 바꾸기

10진수 13을 2진수로 손으로 바꾼 뒤, bin(13)으로 결과를 확인하세요.
정답 보기

8·4·2·1 자리로 나누면 8 + 4 + 1 = 13 → 1101

print(bin(13))
→ 0b1101

실습 5-2. 문자 코드값 출력

알파벳 'B'의 아스키 코드값과, 코드값 48에 해당하는 문자를 각각 출력하세요.
정답 보기
print(ord("B"))   # 66
print(chr(48))    # '0'
66 0

🤖 AI 실습 5-3. AI 계산을 코드로 검증

ChatGPT에게 “내 이름의 첫 글자(영문)의 아스키 코드값”을 물어본 뒤, 파이썬 ord()로 정말 맞는지 직접 확인하세요. AI 답과 코드 결과가 같은지 비교합니다.
검증 예시 보기
영어 대문자 'K'의 아스키 코드값이 몇이야? 계산 과정도 알려 줘.
print(ord("K"))   # AI가 75라고 했다면 → 실제로 75가 맞는지 확인
→ 75

“AI에게 묻고 → 코드로 검증”이 이 과목의 핵심 습관입니다.

자료형 변환(형 변환) · 문자열 다루기

✏️ 실습문제

실습 6-1. 문자열 숫자 더하기

변수 x = "7", y = "3"이 있습니다. 두 값을 더한 값 10이 나오도록 형 변환하여 출력하세요.
정답 보기
x = "7"
y = "3"
print(int(x) + int(y))   # 10
10

만약 변환 없이 x + y를 하면 문자열이 이어져 "73"이 됩니다.

🤖 AI 실습 6-2. 일부러 오류 내고 고치기

일부러 print("7" + 3)처럼 오류가 나는 코드를 실행해 보세요. 나타난 오류 메시지를 그대로 ChatGPT에 붙여넣어 원인과 수정법을 받고, 고친 코드를 실행해 결과를 확인하세요.
예시 흐름 보기

① 오류 재현

print("7" + 3)
TypeError: can only concatenate str (not "int") to str

② 오류 메시지를 AI에 붙여넣고 물어보기 → ③ 고친 코드 실행

print(int("7") + 3)   # 10

오류는 실패가 아니라 가장 좋은 학습 재료입니다. AI와 함께라면 두렵지 않아요.

print("이름:\t파이썬\n취미:\t코딩")

🤖 AI 실습 7-2. 나만의 명함 출력하기

이름·직업·연락처가 줄과 탭으로 예쁘게 정렬된 “텍스트 명함”을 출력하고 싶다고 ChatGPT에 요청해 코드를 받으세요. 실행해 보고, 마음에 안 드는 부분은 “여기를 이렇게 바꿔 줘”라고 다시 요청해 완성하세요.
예시 프롬프트 보기

연산자(Operator) · 입력 처리 input()

✏️ 실습문제

실습 8-1. 몫과 나머지 계산하기

빵 30개를 4명이 나눠 가질 때, 한 사람이 몇 개씩 갖고(몫) 몇 개가 남는지(나머지)를 계산해 출력하세요.
정답 보기
bread = 30
people = 4
print("한 사람 몫:", bread // people, "개")
print("남는 빵:", bread % people, "개")
한 사람 몫: 7 개 남는 빵: 2 개

실습 8-2. 두 변수 값 교환하기

x = 1, y = 2일 때 두 변수의 값을 서로 바꿔 x=2, y=1이 되게 하세요. (힌트: 파이썬은 x, y = y, x처럼 한 줄로 교환 가능)
정답 보기
x = 1
y = 2
x, y = y, x        # 구조 분해 할당으로 값 교환
print(x, y)         # 2 1
2 1

실습 8-3. 논리 연산 결과 예측

다음 식의 결과(True/False)를 먼저 예측한 뒤 실행해 확인하세요.
① 5 > 3 and 2 > 4   ② 5 > 3 or 2 > 4   ③ not (1 == 1)
정답 보기

① False (뒤 조건이 거짓)   ② True (하나만 참이어도 참)   ③ False (참을 뒤집음)

🤖 AI 실습 8-4. 예측 → 실행 → AI 확인

실습 8-3의 세 식의 답을 먼저 스스로 예측해 적으세요. 그다음 IDLE에서 실행해 확인하고, 예측이 틀린 식이 있다면 ChatGPT에게 “왜 이 결과가 나오는지” 물어보세요.
예시 프롬프트 보기
파이썬에서 5 > 3 and 2 > 4 의 결과가 왜 False인지, and 연산자의 규칙과 함께 초보자용으로 설명해 줘.

예측 → 실행 → AI로 이유 확인 순서를 지키면 논리 연산이 확실히 이해됩니다.

✏️ 실습문제

실습 9-1. 사각형 넓이 계산기

가로와 세로 길이를 입력받아 사각형의 넓이(가로 × 세로)를 계산해 출력하는 프로그램을 작성하세요.
실행 결과 예시 가로: 5 세로: 3 사각형의 넓이는 15 입니다.
정답 보기
width = int(input("가로: "))

print("사각형의 넓이는", area, "입니다.")

실습 9-2. 나이 계산 프로그램

태어난 연도를 입력받아, 올해(2026년) 기준 나이를 계산해 출력하세요. (나이 = 2026 − 태어난 연도)
정답 보기
birth = int(input("태어난 연도: "))
age = 2026 - birth
print("당신의 나이는", age, "살입니다.")
태어난 연도: 2000 당신의 나이는 26 살입니다.

    math = student["math"]
    total = kor + eng + math
    average = total / (len(student) - 1)  # 과목 수로 나누어 평균 계산
    print(f"{name}\t{kor}\t{eng}\t{math}\t{total}\t{average:.2f}")
실행 결과 학생 성적표 이름 국어 영어 수학 총점 평균 이대한 95 80 80 255 85.00 박민국 80 75 75 230 76.67 오상식 90 85 90 265 88.33
