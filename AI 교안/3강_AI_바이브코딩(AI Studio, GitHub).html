Google AI Studio Build 시작하기

🎯 학습목표
  • Google AI Studio의 Build 화면에 들어가 앱 만들기를 시작할 수 있다.
  • 미리보기를 보며 말로 수정 요청할 수 있다.
📖 개념 및 설명

Google AI Studio는 Gemini 모델로 프롬프트만으로 앱을 설계 · 구현하는 무료 개발 환경입니다. 그중 Build 화면에 만들고 싶은 앱을 문장으로 적으면, Gemini가 코드를 만들고 오른쪽에 바로 실행되는 미리보기를 보여 줍니다.

  1. aistudio.google.com 접속 → Google 계정으로 로그인
  2. 왼쪽 메뉴에서 Build 선택
  3. 입력창에 만들 앱을 문장으로 입력
  4. Build 버튼 (또는 Ctrl + Enter)으로 실행
  5. 오른쪽 미리보기를 보며 채팅으로 수정 요청 → 원하는 모습이 될 때까지 반복
메뉴 이름은 바뀔 수 있어요 AI Studio는 업데이트가 잦아 메뉴 이름과 위치가 바뀔 수 있습니다. 화면이 조금 달라도 Build(앱 만들기) 메뉴를 찾으면 됩니다. 만든 앱은 GitHub와 연결해 코드를 보관하거나 인터넷에 배포할 수도 있습니다.

GitHub와 GitHub Pages

🎯 학습목표
  • GitHub와 저장소(Repository)가 무엇인지 설명할 수 있다.
  • GitHub Pages로 웹페이지를 무료로 인터넷에 공개하는 원리를 이해한다.
📖 개념 및 설명

지금까지 만든 웹페이지는 내 컴퓨터에서만 열립니다. 다른 사람에게 보여 주려면 인터넷에 올려야 하는데, 이것을 배포(Deploy)라고 합니다.

용어뜻비유
GitHub코드와 파일을 인터넷에 보관하고 함께 관리하는 서비스개발자용 클라우드 창고
저장소 (Repository)프로젝트 하나의 파일을 모아 두는 공간창고 안의 상자 하나
GitHub Pages저장소의 웹페이지 파일을 무료로 인터넷에 공개해 주는 기능상자를 진열대에 올려 누구나 보게 하기
index.html사이트에 들어가면 가장 먼저 열리는 첫 화면 파일가게의 정문

GitHub Pages로 배포하면 주소는 https://내아이디.github.io/저장소이름/ 형태가 됩니다.

GitHub 가입하기 — github.com → Sign up → 이메일 · 비밀번호 · 사용자 이름(아이디) 입력 → 이메일로 온 인증 코드 입력. 아이디는 사이트 주소에 들어가므로 짧고 기억하기 쉽게 정하세요.

⚠️ 무료 배포는 ‘공개(Public)’ 저장소 무료 GitHub Pages는 공개 저장소에서 쓰므로 누구나 파일을 볼 수 있습니다. 개인정보, 비밀번호, API 키가 든 파일은 절대 올리지 마세요.
5

랜딩페이지를 GitHub에 올리고 배포하기

🎯 학습목표
  • 저장소를 만들고 웹 화면에서 파일을 업로드할 수 있다.
  • GitHub Pages를 켜서 내 랜딩페이지를 URL로 공개하고 QR로 공유할 수 있다.
💡 예제 — 2일차 랜딩페이지를 인터넷에 올리기

2일차에 Codex로 만든 랜딩페이지(codex-연습 폴더의 index.html)를 준비합니다. 명령어 없이 웹 화면에서 클릭만으로 진행합니다.

단계하는 일
① 저장소 만들기오른쪽 위 + → New repository → 이름 입력(예: greenpack) → Public 선택 → Add a README 체크 → Create repository
② 파일 올리기저장소 화면에서 Add file → Upload files → index.html(사진이 있으면 함께)을 끌어다 놓기 → 아래 Commit changes
③ Pages 켜기Settings → 왼쪽 Pages → Build and deployment의 Source에서 Deploy from a branch → Branch를 main, 폴더를 / (root)로 고르고 Save
④ 주소 확인1~2분 뒤 Pages 화면 위에 “Your site is live at …”과 주소가 나타남 → 눌러서 내 페이지가 열리는지 확인
⑤ QR로 공유주소를 QR 코드로 만들어 휴대폰으로 스캔 (파이썬 3강의 QR 코드 생성기를 써도 좋아요)
고치고 싶을 때 내용을 고친 index.html을 같은 방법(Add file → Upload files)으로 다시 올리면 됩니다. 잠시 뒤 같은 주소에 새 내용이 반영됩니다. 바뀐 것이 안 보이면 브라우저에서 Ctrl + F5로 새로고침하세요.
⚠️ 첫 화면 파일 이름은 꼭 index.html 파일 이름이 profile.html처럼 다르면 주소 뒤에 /profile.html을 붙여야 열립니다. 첫 화면으로 쓸 파일은 index.html로 이름을 바꿔 올리세요.
✏️ 실습문제

실습 5-1. 내 랜딩페이지 배포하고 QR로 공유하기

2일차에 만든 랜딩페이지(또는 소개 페이지)를 GitHub Pages로 배포하세요. 받은 주소를 QR 코드로 만들어 옆 사람의 휴대폰으로 스캔해 접속되는지 확인하세요.
확인 체크리스트 보기
  • 저장소가 Public인가?
  • 첫 화면 파일 이름이 index.html인가?
  • Settings → Pages에 “Your site is live at …”이 보이는가?
  • 휴대폰에서 QR을 스캔하면 내 페이지가 열리는가?

🤖 AI 실습 5-2. 배포가 안 될 때 AI에게 묻기

배포 주소에 들어갔는데 404가 뜨거나 화면이 깨져 보인다면, 상황을 설명하고 화면을 캡처해 ChatGPT나 Gemini에게 원인을 물어보세요.
예시 프롬프트 보기
GitHub Pages로 웹페이지를 배포했는데 주소에 들어가면 404 페이지가 떠. 저장소는 Public이고, Settings → Pages에서 main 브랜치와 / (root)를 골랐어. 올린 파일 이름은 index.html이야. 초보자가 확인할 순서대로 원인을 알려 줘.

자주 있는 원인: 아직 배포 중(1~2분 기다리기) · 파일 이름 대소문자(Index.html) · 파일을 폴더째 올려 경로가 달라짐

  • AI Studio에서 만든 단위 변환기를 파이썬 창(tkinter)으로도 만들어 볼 수 있다.

📖 개념 및 설명

AI Studio는 웹 앱을 만들어 주지만, 같은 생각을 파이썬으로도 만들 수 있습니다. ChatGPT나 Codex에게 생활 문제를 설명해 코드를 받고, 오후 파이썬 시간에 배울 문법을 미리 만나 봅니다.

문법쉽게 말하면코드 예

예외 처리잘못된 입력에도 프로그램이 멈추지 않게 하기try: … except ValueError:

💡 예제 1 — 오늘의 할 일 메모장 (파일 입출력)

생활 문제 — 할 일을 적어 두고 싶은데, 프로그램을 껐다 켜도 목록이 남아 있으면 좋겠습니다.

파이썬 초보야. 오늘 할 일을 입력받아 todo.txt 파일에 한 줄씩 이어서 저장하고, 다 입력하면 파일 전체를 읽어 번호를 붙여 보여 주는 todo.py를 만들어 줘. 빈 줄을 입력하면 입력을 끝내고, with open을 써서 쉬운 주석을 달아 줘.
# 오늘의 할 일 메모장 (todo.py)
FILE = "todo.txt"          # 할 일을 저장할 파일 이름

# 1) 할 일 입력받아 파일에 덧붙여 저장하기
print("오늘 할 일을 입력하세요. (아무것도 입력하지 않고 Enter → 끝)")
with open(FILE, "a", encoding="utf-8") as f:     # "a": 기존 내용 뒤에 이어 쓰기
    while True:
        task = input("할 일: ").strip()
        if task == "":                            # 빈 줄이면 입력 끝
            break
        f.write(task + "\n")                      # 한 줄에 하나씩 저장

# 2) 파일을 읽어 번호를 붙여 보여 주기
with open(FILE, "r", encoding="utf-8") as f:      # "r": 읽기
    lines = f.readlines()

print("\n=== 나의 할 일 목록 ===")
if len(lines) == 0:                               # 저장된 할 일이 없을 때
    print("아직 저장된 할 일이 없습니다.")
for number, line in enumerate(lines, start=1):
    print(f"{number}. {line.strip()}")
실행 결과 (두 번째 실행) 오늘 할 일을 입력하세요. (아무것도 입력하지 않고 Enter → 끝) 할 일: 책 20쪽 읽기 할 일: === 나의 할 일 목록 === 1. 장보기 2. 운동 30분 3. 책 20쪽 읽기

첫 번째 실행에서 적은 장보기 · 운동 30분이 파일에 남아 있어서, 다시 실행해도 목록에 그대로 나옵니다. 이것이 파일 입출력의 힘입니다.

💡 예제 2 — 파이썬으로 만드는 단위 변환기 (윈도우 + 파일)

생활 문제 — AI Studio에서 만든 단위 변환기를 내 컴퓨터의 창 프로그램으로 만들고, 변환한 기록도 파일에 남기고 싶습니다.

파이썬 tkinter로 길이 단위 변환기 창을 만들어 줘. 센티미터를 입력하고 [미터로 변환] 버튼을 누르면 결과를 창에 보여 주고, 변환 기록을 history.txt에 한 줄씩 저장해 줘. 숫자가 아닌 값을 넣으면 try-except로 '숫자를 입력하세요!'라고 알려 줘. 초보자용 주석을 달아 줘.
# 길이 단위 변환기 (converter.py) — tkinter 창 + 변환 기록 저장
from tkinter import *

def convert():
    try:
        cm = float(entry.get())                   # 입력값을 숫자로 바꾸기
    except ValueError:                            # 숫자가 아니면 예외 처리
        result.config(text="숫자를 입력하세요!")
        return
    m = cm / 100
    text = f"{cm} cm = {m} m"
    result.config(text=text)                      # 창에 결과 표시
    with open("history.txt", "a", encoding="utf-8") as f:
        f.write(text + "\n")                      # 변환 기록을 파일에 저장

window = Tk()
window.title("길이 단위 변환기")
window.geometry("300x160")

Label(window, text="센티미터(cm)를 입력하세요").pack(pady=5)
entry = Entry(window, width=15, justify="center")
entry.pack()
Button(window, text="미터(m)로 변환", command=convert).pack(pady=5)
result = Label(window, text="", font=("맑은 고딕", 12, "bold"))
result.pack()

window.mainloop()
실행 결과 [창] 센티미터(cm)를 입력하세요 [ 250 ] [미터(m)로 변환] 250.0 cm = 2.5 m ← history.txt에도 같은 줄이 저장됨 [창] "abc" 입력 → 숫자를 입력하세요!
코드 속 부분문법
Tk(), Label, Entry, Button, mainloop()tkinter — 창과 부품 만들기
command=convert버튼 클릭 이벤트 — 누르면 함수 실행
try: … except ValueError:예외 처리 — 숫자가 아닐 때 안내
with open("history.txt", "a")파일 쓰기 — 변환 기록 이어서 저장
실행은 IDLE에서 직접 tkinter 창 프로그램은 ChatGPT 대화창 안에서는 실행되지 않습니다. 코드를 IDLE에 붙여넣고 converter.py로 저장한 뒤 F5로 실행하세요.

🤖 AI 실습 6-1. 한 줄씩 설명받기

예제 1이나 2의 코드를 ChatGPT에 붙여넣고 “이 코드를 한 줄씩 초보자도 알 수 있게 설명해 줘”라고 요청하세요. 설명을 읽고 파일 쓰기 · 파일 읽기 · 예외 처리 · tkinter가 쓰인 줄을 각각 찾아 표시해 보세요.
핵심 보기

특히 파일을 여는 모드 "a"(이어 쓰기), "w"(새로 쓰기), "r"(읽기)의 차이를 물어보세요. "w"로 바꾸면 실행할 때마다 예전 할 일이 지워집니다.

🤖 AI 실습 6-2. 단위 변환기에 기능 더하기

예제 2의 변환기에 킬로그램 → 그램 변환 버튼을 하나 더 넣어 달라고 AI에게 요청하세요. 고친 코드를 실행해 2.5 kg → 2500 g이 나오는지 검증하세요.
예시 프롬프트 보기
아래 converter.py에 [그램으로 변환] 버튼을 하나 더 추가해 줘. 입력칸에 킬로그램을 넣고 그 버튼을 누르면 그램으로 바꿔 보여 주고, 이것도 history.txt에 저장해 줘. 기존 기능은 그대로 두고, 바뀐 부분에 주석을 달아 줘. (코드 붙여넣기)

AI Studio에서 메뉴를 더하던 것과 같은 방식입니다. 바꿀 부분만 구체적으로 말하면 됩니다.
