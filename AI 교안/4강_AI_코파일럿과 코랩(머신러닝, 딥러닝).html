GitHub Copilot 시작하기

🎯 학습목표

📖 개념 및 설명

GitHub Copilot은 GitHub이 만든 AI 코딩 도우미입니다. 코드 편집기(VS Code) 안에서 작성 중인 코드의 맥락을 이해하고 다음 줄을 자동으로 제안하며, 주석이나 채팅으로 “이런 걸 만들어 줘”라고 하면 코드를 만들어 줍니다.

사람의 역할목표를 말하고 결과 확인직접 코드를 쓰며 제안을 골라 받기

Copilot 켜기

  1. VS Code 최신 버전을 준비합니다. (요즘 VS Code에는 Copilot이 기본으로 들어 있습니다.)
  2. VS Code 오른쪽 위의 Copilot 아이콘을 누르고 Sign up for Copilot Free(또는 로그인)를 선택합니다.
  3. GitHub(으)로 계속하기 → 3일차에 만든 GitHub 계정을 고르고 Continue를 누르면 연결됩니다.
무료 플랜(Copilot Free) GitHub 계정만 있으면 무료로 쓸 수 있지만, 한 달에 쓸 수 있는 양이 정해져 있고 AI 모델은 자동으로 선택됩니다. 한도에 닿으면 다음 달까지 기다리면 됩니다. 남은 사용량은 VS Code에서 확인할 수 있습니다.

원하는 동작을 주석으로 적고 Enter를 누르면, Copilot이 다음 줄들을 회색으로 제안합니다. Tab을 눌러 하나씩 받아들입니다.

# 1부터 10까지 홀수의 합

💡 예제 2 — 파이썬으로 만드는 단위 변환기 (윈도우 + 파일)

생활 문제 — 3일차 AI Studio에서 웹으로 만든 단위 변환기를 내 컴퓨터의 창 프로그램으로 만들고, 변환한 기록도 파일에 남기고 싶습니다. 이번에는 VS Code에서 Copilot과 함께 만듭니다.

  1. VS Code에서 새 파일을 만들고 converter.py로 저장합니다.
  2. Copilot Chat 창을 열고 아래처럼 요청합니다.
  3. 답변의 코드를 편집기에 넣고(코드 블록 위의 삽입/적용 버튼 또는 복사 · 붙여넣기) 저장합니다.
converter.py에 파이썬 tkinter로 길이 단위 변환기 창을 만들어 줘. 센티미터를 입력하고 [미터로 변환] 버튼을 누르면 결과를 창에 보여 주고, 변환 기록을 history.txt에 한 줄씩 저장해 줘. 숫자가 아닌 값을 넣으면 try-except로 '숫자를 입력하세요!'라고 알려 줘. 초보자용 주석을 달아 줘.
# 길이 단위 변환기 (converter.py) — tkinter 창 + 변환 기록 저장
from tkinter import *

def convert():
    try:
        cm = float(entry.get())                   # 입력값을 숫자로 바꾸기
    except ValueError:                            # 숫자가 아니면 예외 처리
        result.config(text="숫자를 입력하세요!")
        return
    m = cm / 100
    text = f"{cm} cm = {m} m"
    result.config(text=text)                      # 창에 결과 표시
    with open("history.txt", "a", encoding="utf-8") as f:
        f.write(text + "\n")                      # 변환 기록을 파일에 저장

window = Tk()
window.title("길이 단위 변환기")
window.geometry("300x160")

Label(window, text="센티미터(cm)를 입력하세요").pack(pady=5)
entry = Entry(window, width=15, justify="center")
entry.pack()
Button(window, text="미터(m)로 변환", command=convert).pack(pady=5)
result = Label(window, text="", font=("맑은 고딕", 12, "bold"))
result.pack()

window.mainloop()
실행 결과 [창] 센티미터(cm)를 입력하세요 [ 250 ] [미터(m)로 변환] 250.0 cm = 2.5 m ← history.txt에도 같은 줄이 저장됨 [창] "abc" 입력 → 숫자를 입력하세요!
코드 속 부분문법
Tk(), Label, Entry, Button, mainloop()tkinter — 창과 부품 만들기
command=convert버튼 클릭 이벤트 — 누르면 함수 실행
try: … except ValueError:예외 처리 — 숫자가 아닐 때 안내
with open("history.txt", "a")파일 쓰기 — 변환 기록 이어서 저장
VS Code에서 실행하기 편집기 오른쪽 위의 ▷ (Run Python File)을 누르거나, 터미널에서 python converter.py를 입력하면 창이 뜹니다. (Python 확장이 설치되어 있어야 합니다.) 표의 문법은 3일차 파이썬 시간에 배운 내용이니, 코드에서 하나씩 찾아보세요.

💡 예제 1 — 부서별 평균 월급 분석 (코랩 + Gemini)

생활 문제 — 인사 담당자가 “부서별로 몇 명이고 평균 월급은 얼마인지” 표와 그래프로 보고해야 합니다.

  1. 코랩 왼쪽의 📁 파일 아이콘 → 업로드로 직원명단.xlsx를 올립니다.
  2. Gemini 패널에 아래처럼 요청하고, 만들어 준 코드 셀을 실행합니다.
업로드한 직원명단.xlsx를 판다스로 읽어서 전체 직원 수와 평균 월급을 보여 주고, 부서별 인원수와 평균 월급을 평균 월급이 높은 순으로 정리한 다음 막대그래프로 그려 줘. 한글이 깨지지 않게 koreanize-matplotlib를 쓰고, 초보자용 주석을 달아 줘.
!pip install koreanize-matplotlib    # 그래프 한글 글꼴 설치 (코랩에서 처음 한 번)
import pandas as pd
import matplotlib.pyplot as plt
import koreanize_matplotlib            # 그래프 한글 깨짐 방지

# 1. 엑셀 파일 읽기
df = pd.read_excel("직원명단.xlsx")
print(df[["이름", "부서", "월급"]].head(3))

# 2. 전체 요약
print("직원 수:", len(df), "명")
print("평균 월급:", int(df["월급"].mean()), "원")

# 3. 부서별 인원수와 평균 월급 (groupby)
dept = df.groupby("부서")["월급"].agg(["count", "mean"])
dept.columns = ["인원", "평균월급"]
dept["평균월급"] = dept["평균월급"].astype(int)
dept = dept.sort_values("평균월급", ascending=False)   # 높은 순 정렬
print(dept)

# 4. 막대그래프로 그리기
(dept["평균월급"] / 10000).plot(kind="bar", color="steelblue")   # 만 원 단위
plt.title("부서별 평균 월급")
plt.ylabel("평균 월급(만 원)")

💡 예제 2 — 직원 현황 보고서 자동 만들기 (VS Code + Copilot)

생활 문제 — 매달 직원 명단을 받아 요약 시트와 부서별 시트로 나누고, 서식을 꾸미고, 차트를 넣는 데 30분씩 걸립니다.

직원명단.xlsx가 있는 폴더를 VS Code로 열고, Copilot Chat에 요청합니다.

파이썬 초보야. 직원명단.xlsx를 읽어서 부서별 인원 · 월급합계 · 평균월급 요약표를 만들고, '요약' 시트와 부서별 시트로 나눠 직원현황_보고서.xlsx로 저장하는 report.py를 만들어 줘. openpyxl로 제목 행은 파란 배경에 흰 굵은 글씨, 숫자는 천 단위 쉼표, 열 너비는 내용에 맞추고, 요약 시트에 부서별 평균 월급 막대 차트를 넣어 줘. 초보자용 주석을 달아 줘.
import pandas as pd
from openpyxl import load_workbook
from openpyxl.styles import Font, PatternFill, Alignment
from openpyxl.chart import BarChart, Reference

df = pd.read_excel("직원명단.xlsx")
df["입사일"] = pd.to_datetime(df["입사일"]).dt.date     # 날짜만 남기기

# 1. 부서별 요약표 만들기
summary = df.groupby("부서")["월급"].agg(["count", "sum", "mean"]).reset_index()
summary.columns = ["부서", "인원", "월급합계", "평균월급"]
summary["평균월급"] = summary["평균월급"].astype(int)

# 2. 요약 시트 + 부서별 시트로 나눠 한 파일에 저장
with pd.ExcelWriter("직원현황_보고서.xlsx") as writer:
    summary.to_excel(writer, sheet_name="요약", index=False)
    for name, group in df.groupby("부서"):              # 부서마다 반복
        group.to_excel(writer, sheet_name=name, index=False)

# 3. 서식 꾸미기 (openpyxl)
wb = load_workbook("직원현황_보고서.xlsx")
for ws in wb.worksheets:                               # 모든 시트에 반복
    for cell in ws[1]:                                 # 1행(제목 행)
        cell.font = Font(bold=True, color="FFFFFF")
        cell.fill = PatternFill("solid", fgColor="2F6FED")
        cell.alignment = Alignment(horizontal="center")
    for col in ws.columns:
        longest = max(len(str(cell.value)) for cell in col)   # 가장 긴 글자 수
        ws.column_dimensions[col[0].column_letter].width = longest + 6
        for cell in col[1:]:
            if type(cell.value) == int:                 # 숫자면 천 단위 쉼표
                cell.number_format = "#,##0"

# 4. 요약 시트에 막대 차트 넣기
ws = wb["요약"]
chart = BarChart()
chart.title = "부서별 평균 월급"
data = Reference(ws, min_col=4, min_row=1, max_row=ws.max_row)   # 평균월급 열
cats = Reference(ws, min_col=1, min_row=2, max_row=ws.max_row)   # 부서 이름
chart.add_data(data, titles_from_data=True)
chart.set_categories(cats)
ws.add_chart(chart, "F2")

wb.save("직원현황_보고서.xlsx")
print("보고서 완성! 시트 목록:", wb.sheetnames)

🤖 AI 실습 5-2. 월별 매출 파일 합치기

“매출” 폴더에 1월_매출.xlsx · 2월_매출.xlsx · 3월_매출.xlsx(지점, 매출(만원))가 있습니다. 세 파일을 하나로 합쳐 지점별 · 월별 매출표와 1분기 합계를 만드는 코드를 요청하세요. 연습 파일이 없으면 “연습용 파일 3개도 만들어 줘”라고 함께 요청합니다.
정답 · 코드 보기
import glob
import os
import pandas as pd

files = sorted(glob.glob("매출/*_매출.xlsx"))      # 폴더 안 매출 파일 모두 찾기
frames = []
for f in files:
    df = pd.read_excel(f)
    df["월"] = os.path.basename(f).split("_")[0]   # 파일 이름 "1월_매출.xlsx"에서 "1월" 꺼내기
    frames.append(df)

total = pd.concat(frames)                          # 위아래로 이어 붙이기
print(total)

pivot = total.pivot_table(index="지점", columns="월", values="매출(만원)", aggfunc="sum")
pivot["합계"] = pivot.sum(axis=1)
print(pivot)
pivot.to_excel("1분기_매출_합계.xlsx")

머신러닝 맛보기 — 공부 시간으로 성적 예측하기

🎯 학습목표
  • 머신러닝이 데이터로부터 패턴을 학습하는 기술임을 이해한다.
  • Gemini에게 선형 회귀 코드를 받아 학습(fit) → 예측(predict) 흐름을 체험한다.
📖 머신러닝이란?

머신러닝(Machine Learning)은 규칙을 사람이 일일이 코딩하지 않아도, 데이터로부터 패턴을 학습해 예측 · 판단하는 인공지능 기술입니다. 예를 들어 “스팸 메일의 특징”을 직접 정하지 않고, 수많은 메일 데이터를 보여 주면 스스로 규칙을 찾아냅니다.

지도 학습비지도 학습
정답(레이블)있음없음
종류회귀(숫자 예측) · 분류(범주 예측)군집(비슷한 것끼리 묶기)
예집값 · 성적 예측, 스팸 분류, 손글씨 숫자 맞히기고객 구매 패턴 분석, 추천

오늘은 회귀(공부 시간 → 성적)와 분류(손글씨 이미지 → 0~9 숫자)를 하나씩 체험합니다.

💡 예제 — Gemini에게 선형 회귀 만들어 달라고 하기
공부 시간(x)2468
성적(y)81939197
파이썬 초보야. 공부 시간 [2, 4, 6, 8]과 성적 [81, 93, 91, 97] 데이터로 scikit-learn 선형 회귀 모델을 학습시키고, 기울기와 절편을 보여 준 다음 7시간 공부했을 때 성적을 예측하는 코드를 만들어 줘. 쉬운 주석을 달아 줘.
from sklearn.linear_model import LinearRegression

# 1. 데이터 준비 - 공부 시간(x)과 성적(y)
X = [[2], [4], [6], [8]]        # 공부 시간 (2차원: 대괄호 2개)
y = [81, 93, 91, 97]            # 성적

# 2. 모델 만들고 학습(fit)
model = LinearRegression()
model.fit(X, y)

# 3. 학습 결과 - 기울기(a)와 절편(b)
print("기울기 a:", round(model.coef_[0], 2))
print("절편 b:", model.intercept_)

# 4. 예측(predict) - 7시간 공부하면?
print("7시간 공부했을 때 예상 성적:", round(model.predict([[7]])[0], 1))
실행 결과 기울기 a: 2.3 절편 b: 79.0 7시간 공부했을 때 예상 성적: 95.1

AI가 찾은 직선은 y = 2.3x + 79입니다. “공부를 1시간 더 하면 성적이 약 2.3점 오른다”는 패턴을 데이터에서 스스로 배운 것입니다. 7시간이면 2.3 × 7 + 79 = 95.1점으로, 손으로 계산한 값과 같습니다.

학습의 기본 흐름 scikit-learn의 모델은 대부분 fit()으로 학습하고 predict()로 예측하는 같은 구조입니다. 알고리즘만 바꾸면 다른 모델에도 그대로 쓸 수 있습니다.
✏️ 실습문제

🤖 AI 실습 6-1. 예측이 이상할 때 Gemini에게 묻기

같은 모델로 12시간 공부했을 때 성적을 예측해 보세요. 결과가 100점을 넘는다면 왜 그런지 Gemini에게 물어보세요.
정답 · 핵심 보기
12시간 → 2.3 × 12 + 79 = 106.6점
공부 시간 2~8시간 데이터로 만든 선형 회귀가 12시간에 106.6점을 예측했어. 성적은 100점이 최고인데 왜 이런 결과가 나와? 초보자용으로 설명해 줘.

모델은 배운 범위(2~8시간) 밖은 잘 모릅니다. 직선을 그대로 늘려 계산할 뿐이라 100점을 넘깁니다. AI의 예측도 사람이 상식으로 검증해야 하는 이유입니다.

  • 입력층 · 은닉층 · 출력층의 역할을 안다.
📖 딥러닝이란?

딥러닝(Deep Learning)은 인공 신경망을 기반으로 하는 머신러닝의 한 분야입니다. 사람의 뇌처럼 여러 계층(layer)의 신경망을 거치며 데이터를 학습해, 이미지 · 음성처럼 복잡한 패턴을 인식합니다. 1일차에 배운 “기계가 사물을 알아보게 된 순간(2012년)”이 바로 딥러닝 덕분이었습니다.

딥러닝 실습 — 손글씨 숫자 인식 (MNIST)

🎯 학습목표
  • Gemini에게 MNIST 손글씨 분류 모델 코드를 받아 학습시킬 수 있다.
  • 내가 직접 쓴 손글씨를 모델이 맞히는지 시험해 볼 수 있다.
📖 MNIST 데이터셋

MNIST는 0~9까지의 손글씨 숫자 이미지 모음으로, 딥러닝 입문에 가장 널리 쓰이는 데이터셋입니다. 훈련용 60,000개와 테스트용 10,000개, 각각 28×28 픽셀 흑백 이미지입니다.

💡 예제 1 — Gemini에게 손글씨 인식 모델 만들어 달라고 하기
코랩에서 MNIST 손글씨 숫자를 분류하는 딥러닝 모델을 Keras로 만들어 줘. 픽셀값을 0~1로 정규화하고, Flatten → Dense(128, relu) → Dense(10, softmax) 구조로 5번(epochs=5) 학습한 뒤 테스트 정확도를 출력해 줘. 초보자용 주석을 달아 줘.
import tensorflow as tf
from tensorflow.keras import layers, models

# 1. 데이터 준비 - MNIST 손글씨(28x28 흑백)
(X_train, y_train), (X_test, y_test) = tf.keras.datasets.mnist.load_data()
print(X_train.shape)        # (60000, 28, 28)

# 2. 전처리 - 0~255 픽셀값을 0~1로 정규화
X_train = X_train / 255.0
X_test = X_test / 255.0

# 3. 모델 만들기
model = models.Sequential([
    layers.Flatten(input_shape=(28, 28)),      # 2차원 → 1차원(784)
    layers.Dense(128, activation="relu"),      # 은닉층
    layers.Dense(10, activation="softmax")     # 출력층(0~9, 10개)
])

# 4. 컴파일 & 학습
model.compile(optimizer="adam",
              loss="sparse_categorical_crossentropy",
              metrics=["accuracy"])
model.fit(X_train, y_train, epochs=5)

# 5. 평가
loss, acc = model.evaluate(X_test, y_test)
print("정확도:", acc)
실행 결과 (예시) Epoch 5/5 loss: 0.07 accuracy: 0.978 정확도: 0.9765

처음 보는 테스트 이미지 10,000개 중 약 97~98%를 맞힙니다. 학습은 1~2분 정도 걸립니다. (메뉴의 런타임 → 런타임 유형 변경 → GPU를 고르면 더 빨라집니다.)

코드 속 부분뜻
Flatten(input_shape=(28, 28))입력층 — 28×28 이미지를 784개의 한 줄로 펴기
Dense(128, activation="relu")은닉층 — 뉴런 128개가 특징을 찾음
Dense(10, activation="softmax")출력층 — 0~9 중 무엇일지 확률로 답함
model.fit(..., epochs=5)학습 — 전체 데이터를 5번 반복해 공부
💡 예제 2 — 내 손글씨를 AI가 맞힐까?

종이에 굵은 펜으로 숫자 하나를 크게 쓰고, 휴대폰으로 숫자가 가운데 오도록 정사각형에 가깝게 찍어 PC로 옮깁니다. 예제 1의 모델을 학습시킨 노트에서 아래처럼 요청합니다.

방금 학습한 MNIST 모델로 내 손글씨 숫자 사진을 맞혀 보고 싶어. 사진 파일을 업로드받아 흑백으로 바꾸고, 흰 종이에 검은 글씨이니 색을 반전한 다음 28x28로 줄여서 모델이 예측한 숫자를 보여 주는 코드를 만들어 줘.
from google.colab import files
from PIL import Image, ImageOps
import numpy as np

uploaded = files.upload()                 # 내 손글씨 사진 올리기
name = list(uploaded.keys())[0]

img = Image.open(name).convert("L")       # 흑백으로 바꾸기
img = ImageOps.invert(img)                # 흰 종이·검은 글씨 → 검은 배경·흰 글씨
img = img.resize((28, 28))                # MNIST와 같은 28x28 크기로
x = np.array(img) / 255.0                 # 0~1로 정규화
x = x.reshape(1, 28, 28)                  # 이미지 1장 묶음으로

pred = model.predict(x)
print("AI가 읽은 숫자:", pred.argmax())
실행 결과 (예) [파일 선택] my_7.jpg 업로드 AI가 읽은 숫자: 7
⚠️ 틀리게 맞혀도 실패가 아니에요 MNIST는 검은 배경에 흰 글씨, 숫자가 가운데에 있는 이미지로 학습했습니다. 사진에 그림자가 지거나, 글씨가 얇거나, 숫자가 한쪽으로 치우치면 틀리기 쉽습니다. 왜 틀렸는지 Gemini에게 물어보는 것이 오늘의 진짜 공부입니다.

🤖 AI 실습 8-2. 모델 구조를 바꿔 실험하기

은닉층을 하나 더 추가하거나 뉴런 수를 256으로 바꾸면 정확도가 어떻게 달라지는지 Gemini와 함께 실험해 보세요.
예시 프롬프트 보기
이 MNIST 케라스 모델에 은닉층을 하나 더 추가하고 뉴런 수를 256으로 바꾼 코드를 만들어 줘. 바꾸기 전과 후의 테스트 정확도를 나란히 비교해서 보여 주고, 차이가 나는 이유를 쉽게 설명해 줘.

층과 뉴런을 늘리면 대개 정확도가 조금 오르지만 학습 시간이 늘어납니다. 너무 늘리면 오히려 처음 보는 데이터에 약해질 수 있습니다(과적합).
