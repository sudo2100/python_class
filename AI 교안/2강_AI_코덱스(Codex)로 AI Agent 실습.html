📖 개념 및 설명

1일차에 배운 ChatGPT와 Gemini는 묻는 말에 답하는 챗봇이었습니다. 답으로 받은 글이나 코드를 복사해서 쓰는 일은 사람이 직접 했습니다. AI 에이전트(AI Agent)는 한 걸음 더 나아가, 목표를 말하면 스스로 계획을 세우고 직접 실행해 결과물을 만들어 줍니다.

ChatGPT 안의 세 가지 모드

ChatGPT 데스크톱 앱에는 Chat, Work, Codex가 함께 들어 있습니다. Chat은 질문과 대화를, Work는 긴 조사와 완성된 결과물 만들기를 맡고, Codex는 소프트웨어 개발과 기술 작업을 전담하는 에이전트입니다.

모드잘하는 일예
Chat질문 · 검색 · 아이디어 대화“제주도 여행 정보 알려줘”
Work조사 · 분석 · 문서 · 스프레드시트 · 발표 자료 만들기“우리 동네 카페 상권 조사 보고서 만들어 줘”
Codex코드 작성 · 실행 · 수정, 내 컴퓨터 폴더에서 작업“카페 메뉴판 웹페이지를 만들어 줘”
바이브 코딩(Vibe Coding) 코드를 한 줄씩 직접 쓰지 않고, 만들고 싶은 것을 말로 설명해 AI가 코드를 만들게 하는 방식을 말합니다. 오늘 Codex 실습이 바로 바이브 코딩의 첫걸음이고, 3일차 Google AI Studio에서 더 본격적으로 다룹니다.

Codex 시작하기

🎯 학습목표
  • ChatGPT 데스크톱 앱을 설치하고 Codex 화면을 열 수 있다.
  • 작업할 폴더를 열고, 권한(승인) 모드의 의미를 이해한다.
📖 개념 및 설명

Codex는 OpenAI가 만든 AI 코딩 에이전트입니다. 무료(Free) 플랜을 포함한 모든 ChatGPT 요금제에서 쓸 수 있고, 요금제에 따라 사용량만 다릅니다. 무료 플랜에서는 ChatGPT 데스크톱 앱에서 사용합니다. (웹 브라우저의 chatgpt.com에서는 Codex를 고를 수 없습니다.)

설치와 첫 실행

  1. 실습 폴더 만들기 — 바탕화면에 codex-연습 폴더를 새로 만든다. (Codex가 작업할 전용 공간)
  2. 앱 설치 — 운영체제(Windows / Mac)에 맞는 ChatGPT 데스크톱 앱을 내려받아 설치한다.
  3. 로그인 — 1일차에 만든 ChatGPT 계정으로 로그인한다. 전화번호 인증을 요청하면 휴대폰으로 인증한다.
  4. Codex 선택 — 왼쪽 위 메뉴(ChatGPT ▾ / Codex ▾)에서 Codex를 고른다.
  5. 프로젝트 만들기 — 새 채팅을 누르고, 입력창 위의 [프로젝트 선택] → [+ 새 프로젝트]를 고른다. 프로젝트 만들기 창에서 이름에 codex-연습을 쓰고, 소스 폴더의 [폴더 추가]로 1번에서 만든 codex-연습 폴더를 고른 뒤 [프로젝트 만들기]를 누른다. 입력창 위에 폴더 이름이 보이면 준비 완료.

권한(승인) 모드

권한 모드는 Codex가 파일 편집, 명령 실행, 인터넷 사용 같은 작업을 어디까지 혼자 할지 정하는 설정입니다. 입력창 아래 승인 메뉴에서 고르며, 처음에는 승인 요청 모드를 쓰세요. 작업 폴더 안에서는 알아서 일하고, 그 밖으로 나가야 할 때는 멈추고 사람에게 허락을 구합니다.

화면에 보이는 ‘나 대신 승인’은 자동 검토 기능입니다. 사람이 일일이 승인하는 대신, 안전성 검사를 거쳐 대신 승인해 줍니다. 편리하지만 무엇이 승인되는지 배우는 것이 오늘의 목표이므로, 수업에서는 승인 요청 모드로 바꿔 직접 확인합니다.

⚠️ ‘전체 권한’ 모드는 쓰지 마세요 전체 권한으로 실행하면 작업 범위가 작업 폴더로 제한되지 않아, 실수로 다른 파일이 지워지는 등 데이터를 잃을 수 있습니다.
무료 플랜 사용량 무료 플랜은 간단한 작업을 해 보는 정도의 사용량이 주어집니다. 큰 작업을 여러 번 시키면 한도에 걸릴 수 있으니, 수업에서는 짧고 분명한 작업 위주로 실습합니다.

실습 2-1. Codex 첫 인사

Codex에서 codex-연습 폴더를 열고 “이 폴더에 뭐가 있는지 알려 줘”라고 보내 보세요. 이어서 “너는 이 폴더에서 어떤 일을 할 수 있어?”라고 물어보세요.
핵심 보기

빈 폴더라면 “비어 있다”고 답합니다. 챗봇과 달리 Codex는 내 컴퓨터의 폴더를 직접 들여다보고 답한다는 점을 확인하세요.

AI 에이전트가 일하는 모습 — 카페 상권 조사 보고서 — 한 문장으로 요청하면, 에이전트가 스스로 자료를 찾고 정리해 보고서 파일을 만들어 줍니다.

종각역 부근의 카페 상권 조사 보고서 만들어 줘
순서화면에서 보이는 것
① 계획 · ② 실행“1분 28초 동안 작업함” — 그동안 에이전트가 스스로 자료를 찾고, 목차를 짜고, 내용을 썼다 (› 를 누르면 과정을 볼 수 있음)
③ 확인 · ④ 보고보고서에 담은 내용(직장인 수요, 점포 경쟁과 매출, 임대료, 진입 판단 등)과 자료 기준 시점을 요약해 알려 줌
결과물종각역_카페상권_조사보고서.md 파일이 실제로 만들어지고, [보고서 열기]로 바로 확인

챗봇이었다면 화면에 답을 보여 주고 끝났겠지만, 에이전트는 내 폴더에 보고서 파일을 남깁니다. 이 파일은 그대로 저장해 두고, 고치고, 다른 사람에게 보낼 수 있습니다.

.md 파일이란? 마크다운(Markdown) 형식의 문서 파일입니다. 제목 · 굵은 글씨 · 목록 같은 서식을 간단한 기호로 표시하며, 메모장이나 VS Code로 열 수 있습니다.

후속 지시로 Word 파일 만들기 — 회사에서 쓰기 편하도록 같은 대화에서 이어서 요청합니다.

md 파일을 워드 파일로 변환해 줘

에이전트가 변환 작업을 직접 실행해 같은 폴더에 종각역_카페상권_조사보고서.docx 파일을 만들어 줍니다. 제목 · 굵은 글씨 · 목록 서식이 Word 문서에 그대로 옮겨지므로, Word에서 열어 바로 고치거나 인쇄 · 메일 첨부할 수 있습니다.

⚠️ 숫자는 꼭 확인하세요 보고서의 카페 수 · 매출 변화 같은 숫자는 에이전트가 찾은 자료를 정리한 것입니다. 실제 창업 판단처럼 중요한 결정에 쓸 때는 “이 숫자의 출처를 알려 줘”라고 물어 원자료를 확인하세요.

📖 바이브 코딩이란

바이브 코딩(Vibe Coding)은 AI와 몰입형 환경을 활용해 감성적이고 직관적으로 개발에 몰입하는 최신 코딩 트렌드입니다. 한마디로 “정확한 설계나 문서 없이, 감(vibe)에 의존해 말로 빠르게 만드는 방식”입니다. 오늘 Codex로 하는 실습이 바로 바이브 코딩입니다.

🎯 학습목표

💡 예제 1

점심 메뉴 추천 프로그램 — 매일 고민되는 점심 메뉴를 대신 골라 주는 프로그램입니다.

점심 메뉴 추천 프로그램을 lunch.py 파이썬 파일로 만들어 줘. 메뉴는 리스트에 담고, 실행할 때마다 랜덤으로 하나를 골라 보여 줘. 초보자가 이해할 수 있게 주석을 달고, 다 만들면 한 번 실행해서 결과도 보여 줘.

Codex는 파일을 만든 뒤 직접 실행까지 해서 결과를 보여 줍니다. 만들어지는 코드는 대략 아래와 같습니다.

import random   # 무작위로 고르는 기능을 불러온다

# 점심 메뉴 목록 (리스트)
menus = ["김치찌개", "비빔밥", "돈가스", "칼국수", "제육볶음"]

# 메뉴 하나를 골라 주는 함수
def pick_menu():
    return random.choice(menus)

print("오늘의 점심 추천:", pick_menu())
실행 결과 (예) 오늘의 점심 추천: 칼국수
코드 속 요소오늘 배울 파이썬 문법
menus = [ ... ]리스트 — 여러 값을 순서대로 담는 상자
def pick_menu():사용자 함수 — 자주 쓰는 동작에 이름을 붙여 묶은 것
print(), random.choice()내장 함수 · 모듈 — 파이썬이 미리 준비해 둔 기능
이해하고 넘어가기 실행이 됐다고 끝이 아닙니다. Codex에게 “이 코드를 한 줄씩 쉽게 설명해 줘”라고 요청해, 오후 파이썬 시간에 배울 문법과 연결해 보세요.
💡 예제 2

용돈기입장 만들기 — 항목별 지출을 딕셔너리에 담고, 합계를 구하는 함수를 써서 항목별 금액과 합계를 보여 주는 프로그램입니다.

이번 주 지출을 정리하는 용돈기입장 프로그램을 money.py로 만들어 줘. 식비 35000, 교통비 12000, 카페 9000, 책 15000을 딕셔너리에 담고, 합계를 구하는 함수를 만들어서 항목별 금액과 합계를 보기 좋게 출력해 줘. 주석도 달고 실행 결과도 보여 줘.

Codex가 만든 코드는 대략 아래와 같습니다.

# 항목별 지출 (딕셔너리: 이름표와 값의 짝)
spending = {"식비": 35000, "교통비": 12000, "카페": 9000, "책": 15000}

def total(data):
    return sum(data.values())   # 값들만 모아 더한다

for item, cost in spending.items():
    print(f"{item}: {cost:,}원")
print(f"합계: {total(spending):,}원")

결과 검증하기 Codex가 만든 코드는 이와 조금 다를 수 있습니다. 합계가 71,000원으로 맞는지 직접 계산해 검증하세요. 완성되면 Codex에게 “이 코드를 한 줄씩 쉽게 설명해 줘”라고 요청해 보세요.
💡 예제 3

택시 요금 계산기 만들기 — 이동 거리를 넣으면 서울 택시 요금을 계산해 주는 함수를 만듭니다. 주간 요금을 기본값으로 두고, 심야일 때만 요금을 바꿔 넘깁니다.

파이썬 초보야. 서울 택시 요금을 계산하는 taxi.py를 만들어 줘.
요금 기준: 1.6km까지 기본요금 4,800원, 이후 131m마다 100원. 심야 22~23시 · 02~04시는 5,800원 · 120원, 23~02시는 6,700원 · 140원.
taxi_fare(거리, 기본요금=4800, 단위요금=100) 함수로 만들고, 1km · 5km 주간과 5km 심야 요금을 출력해 실행 결과도 보여 줘.

Codex가 실제로 만든 taxi.py입니다. 함수 설명(docstring)과 주석까지 꼼꼼히 달아 주었습니다.

import math  # 초과 거리를 요금 단위로 올림 계산할 때 사용합니다.


def taxi_fare(distance, base_fare=4800, unit_fare=100):
    """거리(km)를 받아 택시 요금을 계산합니다.

    기본요금은 1.6km까지 적용하고, 초과 거리는 131m마다 단위요금을 더합니다.
    """
    base_distance = 1.6  # 기본요금에 포함되는 거리(km)입니다.
    extra_unit_meters = 131  # 추가 요금 한 단위에 해당하는 거리(m)입니다.

    # 기본 거리보다 짧거나 같으면 기본요금만 받습니다.
    if distance <= base_distance:
        return base_fare

    # 기본 거리를 넘은 거리를 미터로 바꿉니다.
    extra_meters = (distance - base_distance) * 1000

    # 초과 거리에 필요한 요금 단위 수를 계산합니다.
    # math.ceil은 남은 거리도 한 단위로 계산하도록 올림합니다.
    extra_units = math.ceil(extra_meters / extra_unit_meters)

    # 기본요금에 초과 거리 요금을 더해 돌려줍니다.
    return base_fare + extra_units * unit_fare


# 주간 요금: 기본요금 4,800원, 131m마다 100원입니다.
print("주간 요금")
print(f"1km: {taxi_fare(1):,}원")
print(f"5km: {taxi_fare(5):,}원")

# 심야 22~23시와 02~04시는 기본요금 5,800원, 131m마다 120원입니다.
print("\n심야 요금 (22~23시 · 02~04시)")
print(f"5km: {taxi_fare(5, base_fare=5800, unit_fare=120):,}원")

# 심야 23~02시는 기본요금 6,700원, 131m마다 140원입니다.
print("\n심야 요금 (23~02시)")
print(f"5km: {taxi_fare(5, base_fare=6700, unit_fare=140):,}원")
실행 결과 주간 요금 1km: 4,800원 5km: 7,400원 심야 요금 (22~23시 · 02~04시) 5km: 8,920원 심야 요금 (23~02시) 5km: 10,340원
코드 속 요소오늘 배울 파이썬 문법

if distance <= base_distance:조건문 — 기본 거리 이내면 기본요금만 돌려줌
import math · math.ceil()모듈 — 남은 거리도 한 단위로 올림해서 계산
결과 검증하기 · 요금 기준은 프롬프트에 직접 5km는 1.6km를 넘은 3,400m를 더 달렸고, 3,400 ÷ 131 = 25.95…입니다. Codex는 math.ceil로 올림해서 26단위로 계산했기 때문에 주간 요금은 4,800 + 26 × 100 = 7,400원입니다. 131m를 다 채운 만큼만 받는 내림으로 계산하면 25단위, 7,300원이 됩니다. 이처럼 AI는 프롬프트에 없는 부분을 스스로 정해서 만들기 때문에, 결과를 직접 계산해 보고 원하는 방식(“131m를 다 채울 때마다 100원”)을 프롬프트에 적어 다시 요청하세요. AI가 알고 있는 택시 요금은 예전 요금일 수 있으니 요금 기준도 프롬프트에 직접 적어 주세요. (기준: 서울시 택시요금, 2026년 현재)

🤖 AI 실습 4-2. 퀴즈 생성 프로그램

간단한 수학 퀴즈 프로그램을 Codex에게 만들게 하세요. 미리 준비한 문제 5개를 무작위 순서로 내고, 답을 입력받아 맞았는지 알려 준 뒤, 마지막에 맞힌 개수 · 틀린 개수 · 정답률을 보여 주는 프로그램입니다. 완성되면 문제까지 무작위로 새로 만들어 내도록 고쳐 보세요.
예시 프롬프트 · 실행 화면 · 검증 체크리스트 보기

STEP 1 — 기본 퀴즈 만들기

파이썬 초보야. quiz.py로 덧셈 문제 5개와 정답을 딕셔너리에 담아, 무작위 순서로 하나씩 내는 수학 퀴즈를 만들어 줘.
input()으로 답을 받아 맞으면 "정답입니다!", 틀리면 정답을 알려 주고, 다 풀면 맞힌 개수 · 틀린 개수 · 정답률(%)을 보여 줘.
딕셔너리 · 리스트 · 반복문 · 조건문을 쓰고, 초보자용 주석을 달아 줘.

STEP 1 결과 — Codex가 만든 quiz.py (예시)

# 수학 퀴즈 프로그램 (quiz.py)
# random 모듈: 문제 순서를 무작위로 섞을 때 사용합니다.
import random

# 1) 딕셔너리: "문제": "정답" 짝으로 5문제를 저장합니다.
quiz = {
    "1 + 1": "2",
    "2 + 3": "5",
    "3 + 7": "10",
    "4 + 2": "6",
    "5 + 9": "14",
}

# 2) 리스트: 딕셔너리의 문제(키)만 꺼내 리스트로 만들고, 순서를 섞습니다.
questions = list(quiz.keys())
random.shuffle(questions)

# 맞힌 개수와 틀린 개수를 셀 변수 (처음에는 0)
correct = 0
wrong = 0

# 반복문: 섞인 문제를 하나씩 꺼내 출제합니다.
# enumerate()는 번호(0, 1, 2 …)와 문제를 함께 꺼내 줍니다.
for number, question in enumerate(questions, start=1):
    print(f"[문제 {number}] {question} = ?")

    # 3) input()으로 답을 받습니다. strip()은 앞뒤 빈칸을 지워 줍니다.
    answer = input("답: ").strip()

    # 조건문: 입력한 답과 정답을 비교합니다.
    if answer == quiz[question]:
        print("정답입니다!")
        correct = correct + 1
    else:
        print(f"틀렸습니다. 정답은 {quiz[question]}입니다.")
        wrong = wrong + 1

    print()  # 문제 사이에 빈 줄 한 칸

# 4) 결과 요약: 맞힌 개수, 틀린 개수, 정답률(%)
total = len(questions)
rate = correct / total * 100

print("===== 퀴즈 결과 =====")
print(f"맞힌 개수: {correct}개")
print(f"틀린 개수: {wrong}개")
print(f"정답률: {rate:.1f}%")

딕셔너리(quiz) · 리스트(questions) · 반복문(for) · 조건문(if/else)이 모두 들어 있습니다. 수강생의 Codex가 만든 코드는 이와 조금 다를 수 있습니다.

STEP 2 — 문제를 무작위로 만들기

quiz.py를 고쳐서 문제를 미리 정해 두지 말고, 1~20 사이 숫자 두 개를 무작위로 골라 덧셈 · 뺄셈 문제 5개를 새로 만들어 내게 해 줘. 문제 수는 변수 하나만 바꾸면 조절되게 해 줘.
실행은 내가 직접 이 프로그램은 input()으로 답을 입력해야 해서, Codex가 대신 풀 수 없습니다. 명령 프롬프트(또는 Codex의 터미널)에서 codex-연습 폴더로 이동해 python quiz.py를 입력하고 직접 풀어 보세요. 방법을 모르면 Codex에게 “quiz.py 실행 방법을 알려 줘”라고 물어보세요.
실행 화면 (예) [문제 1] 3 + 7 = ? 답: 10 정답입니다! [문제 2] 1 + 1 = ? 답: 2 정답입니다! [문제 3] 5 + 9 = ? 답: 13 틀렸습니다. 정답은 14입니다. [문제 4] 2 + 3 = ? 답: 5 정답입니다! [문제 5] 4 + 2 = ? 답: 8 틀렸습니다. 정답은 6입니다. ===== 퀴즈 결과 ===== 맞힌 개수: 3개 틀린 개수: 2개 정답률: 60.0%

실행 후 스스로 점검 (검증 체크리스트)

  • 실행할 때마다 문제 순서가 바뀌는가? (random.shuffle)
  • 일부러 틀린 답을 넣으면 정답을 알려 주는가?
  • 5문제 중 3개를 맞히면 정답률이 60.0%로 나오는가? (3 ÷ 5 × 100)
  • 답 앞뒤에 빈칸을 넣거나 글자를 넣으면 어떻게 되는가? 문제가 있으면 “답 앞뒤의 빈칸은 무시하고, 숫자가 아니면 다시 입력받게 고쳐 줘”라고 요청
  • 코드에서 딕셔너리 · 리스트 · for · if가 어디에 쓰였는지 찾았는가? 모르면 “한 줄씩 설명해 줘”

수칙이렇게 하세요
① 전용 폴더실습은 codex-연습처럼 빈 폴더에서. 회사 자료 · 사진 · 문서 폴더를 통째로 열지 않는다.
② 승인 요청 모드처음에는 승인 요청 모드를 쓰고, ‘전체 권한’은 쓰지 않는다.
③ 승인 전에 읽기Codex가 허락을 구하면 무엇을 하려는지 읽고, 모르겠으면 “이게 무슨 뜻이야?”라고 먼저 묻는다.
④ 결과 확인변경 사항(diff)과 실행 결과를 보고, 숫자 · 내용이 맞는지 직접 검증한다.
⑤ 개인정보 금지비밀번호 · 주민번호 · 고객 정보가 든 파일은 작업 폴더에 넣지 않는다.
⚠️ 이런 승인 요청은 한 번 더 생각하세요 파일 삭제, 작업 폴더 밖의 파일 수정, 프로그램 설치, 인터넷에서 무언가 내려받기 — 이유를 모르면 승인하지 말고 먼저 물어보세요.
