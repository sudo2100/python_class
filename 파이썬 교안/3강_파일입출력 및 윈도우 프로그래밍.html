예외 처리 — try ~ except

🎯 학습목표
  • 구문 오류와 예외(실행 오류)의 차이를 안다.
  • try ~ except로 예외를 처리할 수 있다.
  • 다중 예외와 raise를 사용할 수 있다.
📖 에러와 예외

오류는 크게 둘로 나뉩니다. 구문(Syntax) 오류는 문법이 틀려 실행 전에 IDE가 잡아 줍니다. 예외(Exception)는 문법은 맞지만 실행 중에 발생합니다. 예: 없는 파일 읽기, 리스트에 없는 요소 접근 등. 예외가 나면 프로그램이 중지·종료되므로 안전하게 처리해야 합니다.

예외 클래스발생 상황
ZeroDivisionError0으로 나눌 때
ValueError숫자 칸에 문자를 넣는 등 값이 부적절할 때
IndexError리스트 범위를 벗어난 인덱스 접근
KeyError딕셔너리에 없는 키 접근
FileNotFoundError없는 파일을 열려 할 때

이 예외들은 모두 Exception을 부모로 하는 계층 구조에 속합니다.

try:
    예외가 발생할 수 있는 코드
except 예외클래스:
    예외가 발생했을 때 실행할 코드
💡 예제 — 예외 종류별로 잡기

발생하는 예외 종류에 맞는 except로 각각 안내 메시지를 출력합니다. as e로 오류 내용도 함께 볼 수 있습니다.

try:
    print('20' + 20)
except TypeError as e:
    print("자료형 오류가 발생했습니다:", e)

try:
    print(10 / 0)
except ZeroDivisionError as e:
    print("0으로 나눌 수 없습니다:", e)

try:
    message = "Good Luck!" + friend
except NameError as e:
    print("변수가 정의되지 않았습니다:", e)
실행 결과 자료형 오류가 발생했습니다: can only concatenate str (not "int") to str 0으로 나눌 수 없습니다: division by zero 변수가 정의되지 않았습니다: name 'friend' is not defined
as e except 예외 as e로 받으면 e에 오류 메시지가 담겨, 무엇이 잘못됐는지 자세히 알 수 있습니다.
💡 예제 — 다중 try ~ except 
try:
    num = int(input("숫자 입력: "))
    print("10 ÷ 입력값 =", 10 / num)
except ValueError:
    print("숫자만 입력하세요!")
except ZeroDivisionError:
    print("0으로 나눌 수 없습니다!")
실행 예시 숫자 입력: 0 0으로 나눌 수 없습니다! 숫자 입력: abc 숫자만 입력하세요!
다중 except except를 여러 개 두면 예외 종류별로 다르게 대응할 수 있습니다. 모두 잡고 싶으면 except Exception as e:를 씁니다.
💡 예제 — raise로 예외 일으키기

raise는 내가 정한 조건에서 예외를 의도적으로 발생시킬 때 씁니다.

def set_age(age):
    if age < 0:
        raise ValueError("나이는 0 이상이어야 합니다")
    print("나이:", age)

try:
    set_age(-5)
except ValueError as e:
    print("오류:", e)
실행 결과 오류: 나이는 0 이상이어야 합니다

파일 입출력 — open

🎯 학습목표
  • 파일 입출력의 필요성과 흐름을 설명할 수 있다.
  • open의 모드(w·r·a)를 구분해 사용한다.
  • 파일에 쓰고 읽고 닫을 수 있다.
📖 개념 및 설명

프로그램이 종료되면 메모리의 데이터는 사라집니다. 계속 보관하려면 파일에 저장하고 필요할 때 읽어야 합니다. 파일 입출력은 열기 → 읽기/쓰기 → 닫기의 흐름입니다.

스트림(stream) 자료가 물 흐르듯 오가는 통로입니다. 파일에서 프로그램으로 읽어오면 입력 스트림(f.read()), 프로그램에서 파일로 내보내면 출력 스트림(f.write())입니다.
메서드 / 모드기능
open(파일, "w")쓰기 모드 (기존 내용 삭제)
open(파일, "r")읽기 모드
open(파일, "a")추가 쓰기 모드 (뒤에 붙임)
write() / read()내용 쓰기 / 읽기
close()파일 닫기
💡 예제 — 쓰기·읽기·추가 
# 쓰기 (w: 새로 만들거나 덮어쓰기)
f = open("file.txt", "w", encoding="utf-8")
f.write("안녕하세요\n")
f.write("파이썬 파일 입출력\n")
f.close()

# 추가 (a: 기존 내용 뒤에 붙임)
f = open("file.txt", "a", encoding="utf-8")
f.write("한 줄 더 추가\n")
f.close()

# 읽기 (r)
f = open("file.txt", "r", encoding="utf-8")
print(f.read())
f.close()

# 예외 처리 — 파일이 없을 때 안전하게
try:
    f = open("file.txt", "r", encoding="utf-8")
    print(f.read())
except FileNotFoundError:
    print("파일이 존재하지 않습니다.")
finally:
    f.close()
실행 결과 안녕하세요 파이썬 파일 입출력 한 줄 더 추가
⚠️ w 모드 주의 "w"로 열면 기존 내용이 모두 지워집니다. 이어 붙이려면 "a"(추가) 모드를 쓰세요. 또 close()를 잊으면 내용이 제대로 저장되지 않을 수 있습니다.

with ~ as 구문과 타자 게임

🎯 학습목표
  • with ~ as 구문의 장점을 설명할 수 있다.
  • close() 없이 안전하게 파일을 다룰 수 있다.
  • 파일과 random·time을 합쳐 타자 게임을 만든다.
📖 with ~ as 구문

with ~ as로 파일을 열면, 블록을 벗어날 때 에러 발생 여부와 관계없이 자동으로 close()가 호출됩니다. 코드가 간결하고 안전합니다.

with open(파일이름) as 파일객체:
    코드 블록   # 블록을 벗어나면 자동으로 close()
💡 예제 — 구구단 쓰기 · 리스트 쓰고 읽기 
# 구구단(2단) 파일에 쓰기
with open("gugu.txt", "w", encoding="utf-8") as f:
    for i in range(1, 10):
        f.write(f"2 x {i} = {2*i}\n")

# 리스트를 저장하고 다시 리스트로 읽기
fruits = ["사과", "바나나", "포도"]
with open("fruits.txt", "w", encoding="utf-8") as f:
    for fruit in fruits:
        f.write(fruit + "\n")

with open("fruits.txt", "r", encoding="utf-8") as f:
    lines = [line.strip() for line in f]
print(lines)
실행 결과 ['사과', '바나나', '포도']
💡 예제 — 영어 타자 게임 (파일 + random + time)

파일에서 단어를 읽어와, 랜덤으로 문제를 내고 걸린 시간을 재는 게임입니다.

import random
import time

# 파일에서 단어 읽기
try:
    with open("typing_game/word.txt", "r") as f:
        # strip() 메서드를 사용하여 각 줄의 공백 제거
        word_list = [line.strip() for line in f]
except FileNotFoundError :
    print("파일이 존재하지 않습니다.")

print("[타자 게임] 준비되면 엔터!")
input()
start = time.time()            # 시작 시간

n = 1
while n <= 5:
    q = random.choice(word_list)
    print("제시어:", q)
    if input() == q:
        print("통과!")
        n += 1
    else:
        print("오타! 다시 도전!")

print(f"게임 종료! 걸린 시간: {time.time()-start:.2f}초")
word.txt python programming challenge developer algorithm

바이너리 파일과 pickle

🎯 학습목표
  • 바이너리 파일이 무엇인지 안다.
  • rb·wb 모드로 이미지 등을 복사할 수 있다.
  • pickle로 객체를 그대로 저장·복원할 수 있다.
📖 바이너리 파일

바이너리 파일은 이미지·음성처럼 0과 1로 이루어진 파일입니다. 텍스트가 아니므로 바이트 모드로 열어야 합니다.

모드설명
wb바이너리 쓰기
rb바이너리 읽기
# 이미지 복사하기 (읽어서 다른 이름으로 쓰기)
with open("cat.jpg", "rb") as src:
    data = src.read()

with open("cat_copy.jpg", "wb") as dst:
    dst.write(data)

print("복사 완료, 크기:", len(data), "바이트")
📖 pickle 모듈

pickle은 리스트·딕셔너리 같은 객체의 형태를 그대로 유지하며 파일에 저장하고 불러오는 모듈입니다.

함수설명
pickle.dump(객체, 파일)객체 저장(쓰기)
pickle.load(파일)객체 불러오기(읽기)
import pickle

data = {"이름": "홍길동", "점수": [90, 85, 100]}

# 객체 저장 (바이너리 모드)
with open("data.pkl", "wb") as f:
    pickle.dump(data, f)

# 객체 그대로 복원
with open("data.pkl", "rb") as f:
    loaded = pickle.load(f)

print(loaded)
print(type(loaded))   # 딕셔너리 그대로!
실행 결과 {'이름': '홍길동', '점수': [90, 85, 100]} <class 'dict'>
텍스트 vs pickle 텍스트 파일은 문자열만 저장하지만, pickle은 파이썬 객체(리스트·딕셔너리 등)를 통째로 저장·복원합니다. 단, pickle은 파이썬 전용 형식입니다.

GUI와 tkinter 기초

🎯 학습목표
  • GUI(그래픽 사용자 인터페이스)가 무엇인지 이해한다.
  • tkinter로 창(윈도우)을 만들고 제목·크기를 지정할 수 있다.
  • 라벨·버튼 같은 위젯을 창에 올릴 수 있다.
📖 개념 및 설명

GUI(Graphical User Interface)는 화면의 메뉴·버튼·입력창으로 사용자와 상호작용하는 프로그램입니다. 우리가 매일 쓰는 대부분의 앱이 GUI 프로그램이죠. 지금까지 만든 콘솔(검은 화면) 프로그램과 달리, 창이 뜨고 마우스로 클릭할 수 있습니다.

파이썬은 표준 라이브러리 tkinter로 GUI를 만듭니다. 별도 설치 없이 import tkinter로 바로 쓸 수 있어요. GUI 프로그램의 뼈대는 다음 표처럼 항상 같은 순서를 따릅니다.

단계코드설명
모듈 가져오기from tkinter import *tkinter의 모든 위젯 사용
윈도우 생성root = Tk()기본 창(루트 윈도우) 만들기
제목 지정root.title("제목")창 제목 표시줄 글자
위젯 구성Label(...), Button(...)라벨·버튼 등을 배치
실행(대기)root.mainloop()창을 띄우고 이벤트를 기다림
자주 쓰는 위젯 Label(글자 표시), Button(버튼), Entry(한 줄 입력상자), Text(여러 줄 출력상자), Frame(위젯을 담는 상자).
💡 예제

제목이 있는 창을 만들고, 라벨과 버튼을 올린 가장 기본적인 tkinter 프로그램입니다.

from tkinter import *

root = Tk()                       # 1. 기본 창 생성
root.title("첫 GUI 프로그램")         # 2. 창 제목
root.geometry("300x150")          # 3. 창 크기(너비x높이)

Label(root, text="안녕하세요! 👋").pack()   # 4. 라벨 배치
Button(root, text="확인").pack()          # 5. 버튼 배치

root.mainloop()                  # 6. 창 띄우고 대기
실행 결과 "첫 GUI 프로그램" 제목의 300x150 창이 뜨고, "안녕하세요! 👋" 라벨과 [확인] 버튼이 세로로 나타납니다.

⚠️ mainloop() 필수 root.mainloop()가 없으면 창이 떴다가 바로 사라집니다. GUI 코드의 맨 마지막 줄에 꼭 넣으세요.
✏️ 실습문제

실습 5-1. 내 첫 창 만들기

제목이 "내 이름의 앱", 크기가 320x200인 창을 만들고, 자기 이름을 표시하는 라벨과 [닫기] 버튼을 배치하세요.

root = Tk()

root.mainloop()

레이아웃 — pack()과 grid()

🎯 학습목표
  • 위젯을 화면에 배치하는 레이아웃 매니저의 역할을 이해한다.
  • pack()으로 위/아래/좌/우로 쌓아 배치할 수 있다.
  • grid()로 행·열 격자에 배치할 수 있다.
📖 개념 및 설명

위젯을 만들기만 해서는 화면에 안 나옵니다. 레이아웃 매니저로 "어디에 놓을지"를 정해야 보입니다. tkinter에는 pack(), grid(), place() 세 가지가 있고, 입문 단계에서는 pack과 grid를 씁니다.

방식특징주요 옵션
pack()위젯을 한 방향으로 쌓아서 배치(한 줄에 하나씩이 기본)side, fill, padx, pady
grid()표처럼 행(row)·열(column) 격자에 배치, 한 줄에 여러 개 가능row, column, columnspan
⚠️ 섞어 쓰지 마세요 같은 컨테이너(창·프레임) 안에서는 pack()과 grid()를 함께 쓰면 안 됩니다. 프로그램이 멈춘 것처럼 반응이 없어집니다. 하나를 골라 통일하세요.
💡 예제 — pack()

side 옵션으로 버튼을 좌우로 나란히 붙일 수 있습니다.

from tkinter import *

root = Tk()
root.geometry("260x80")

Button(root, text="왼쪽").pack(side="left", padx=5)
Button(root, text="가운데").pack(side="left", padx=5)
Button(root, text="오른쪽").pack(side="left", padx=5)

root.mainloop()
실행 결과 [왼쪽] [가운데] [오른쪽] 버튼이 가로로 나란히 배치됩니다.

💡 예제 — grid()

간단한 로그인 폼처럼 라벨과 입력창을 격자에 배치합니다.

from tkinter import *

root = Tk()
root.title("로그인")

Label(root, text="아이디").grid(row=0, column=0, padx=5, pady=5)
Entry(root).grid(row=0, column=1)
Label(root, text="비밀번호").grid(row=1, column=0, padx=5, pady=5)
Entry(root, show="*").grid(row=1, column=1)
Button(root, text="로그인").grid(row=2, column=0, columnspan=2, pady=8)

root.mainloop()
실행 결과 아이디 / 비밀번호 라벨과 입력칸이 2행으로 정렬되고, 맨 아래 [로그인] 버튼이 두 칸에 걸쳐 배치됩니다.

columnspan 여러 열을 하나로 합쳐 넓게 배치합니다. 표의 '셀 병합'과 같은 개념입니다.

실습 6-1. 3x3 버튼판

grid()를 이용해 1~9 숫자가 적힌 버튼 9개를 3행 3열로 배치한 창을 만드세요.

from tkinter import *

root = Tk()

n = 1

버튼 클릭 이벤트

🎯 학습목표
  • 버튼을 눌렀을 때 실행할 함수(이벤트 핸들러)를 연결할 수 있다.
  • command 옵션에 함수를 괄호 없이 넘기는 이유를 안다.
  • 입력창(Entry)의 값을 읽어 라벨에 결과를 표시할 수 있다.
📖 개념 및 설명

버튼은 누를 때 무언가 실행되어야 의미가 있습니다. tkinter는 버튼의 command 옵션에 실행할 함수를 연결합니다.

⚠️ 괄호에 주의 command=click처럼 괄호 없이 함수 이름만 넘깁니다. command=click()처럼 괄호를 붙이면 버튼을 만드는 순간 함수가 실행되어 버립니다. 괄호를 빼야 클릭할 때 실행됩니다.

💡 예제 — 콘솔에 출력

버튼을 누르면 함수가 호출되어 콘솔에 글자를 출력합니다.

from tkinter import *

def click():                 # 버튼을 누르면 실행될 함수
    print("버튼이 눌렸습니다!")

root = Tk()
Button(root, text="확인", command=click).pack(padx=20, pady=20)
# command=click  → 괄호 없이! 클릭할 때 실행
root.mainloop()
실행 결과 (버튼을 누를 때마다 콘솔에) 버튼이 눌렸습니다!
💡 예제 — 입력값을 라벨에 출력

입력창에 쓴 이름을 읽어 인사말을 라벨에 표시합니다.

from tkinter import *

def greet():
    name = entry.get()             # 입력창의 글자 읽기
    result.config(text="안녕하세요, " + name + "님!")  # 라벨 글자 변경

root = Tk()
root.title("인사 프로그램")

entry = Entry(root)
entry.pack(padx=10, pady=10)
Button(root, text="인사하기", command=greet).pack()
result = Label(root, text="")      # 결과를 표시할 빈 라벨
result.pack(pady=10)

root.mainloop()
실행 결과 입력창에 "파이썬"을 쓰고 [인사하기]를 누르면 → 안녕하세요, 파이썬님!

핵심 3단계 ① entry.get()으로 입력값 읽기 → ② 결과 문자열 만들기 → ③ label.config(text=...)로 화면에 반영.
✏️ 실습문제

실습 7-1. 클릭 카운터

버튼을 누를 때마다 숫자가 1씩 올라가 라벨에 "클릭 횟수: N"으로 표시되는 프로그램을 만드세요.
정답 보기
from tkinter import *

count = 0
def add():
    global count
    count += 1
    label.config(text="클릭 횟수: " + str(count))

root = Tk()
label = Label(root, text="클릭 횟수: 0", font=("맑은 고딕", 14))
label.pack(pady=10)
Button(root, text="누르기", command=add).pack(pady=5)
root.mainloop()

미니 프로젝트: 컴퓨터 용어 사전

🎯 학습목표
  • 딕셔너리 자료구조로 용어–뜻 데이터를 저장한다.
  • 입력창·버튼·출력상자를 조합해 검색 앱을 완성한다.
  • 검색 결과가 없을 때의 처리를 넣는다.
📖 개념 및 설명

지금까지 배운 딕셔너리와 tkinter를 합쳐 실제 쓸 수 있는 앱을 만듭니다. 용어와 뜻을 딕셔너리에 미리 저장해 두고, 단어를 입력해 [검색]을 누르면 출력상자에 뜻을 보여 줍니다. 없는 단어면 "사전에 없는 용어입니다."라고 안내합니다.

  • 데이터: {"CPU": "중앙처리장치...", ...} 딕셔너리
  • 입력: Entry에 단어 입력
  • 처리: dict.get(단어)로 뜻 찾기(없으면 안내문)
  • 출력: Text 상자에 결과 표시
💡 예제 — 컴퓨터용어사전.py 
from tkinter import *

# 딕셔너리 자료 생성
dic = {
    "변수": "데이터를 저장하기 위한 공간으로, 이름과 값으로 구성됩니다. ",
    "함수": "특정 작업을 수행하는 코드 블록으로, 재사용이 가능하며 입력과 출력을 가질 수 있습니다. ",
    "CPU": "중앙 처리 장치(Central Processing Unit)의 약자로, 컴퓨터의 두뇌에 해당하는 핵심 부품입니다. ",
    "RAM": "임의 접근 메모리(Random Access Memory)의 약자로, 컴퓨터가 작업을 수행하는 동안 데이터를 일시적으로 저장하는 메모리입니다. ",
}

# 검색 함수 정의
def search():
    word = entry.get().strip().upper() # 입력 상자에서 단어 가져오기(공백제거)
    meaning = dic.get(word, "사전에 없는 용어입니다.") #없으면 안내문
    output.delete(1.0, END) #이전 결과 지우기
    output.insert(END, word + " : " + meaning) #결과 출력

# 메인 윈도우 생성
window = Tk()
window.title("컴퓨터 용어 사전")

# 검색어 입력 레이블과 엔트리(입력상자- 한줄)
Label(window, text="용어를 입력하세요:") \
.grid(row=0, column=0, sticky=W, padx=10, pady=5)

entry = Entry(window, width=30)
entry.grid(row=1, column=0, sticky=W, padx=10, pady=5)

# 검색 버튼
Button(window, text="검색", command=search) \
.grid(row=2, column=0, sticky=W, padx=10, pady=5)

# 결과 출력 텍스트(여러줄)
output = Text(window, width=50, height=10)
output.grid(row=3, column=0, sticky=W, padx=10, pady=5)

window.mainloop()
실행 결과 "변수" 입력 후 [검색] → 변수 : 데이터를 저장하기 위한 공간으로, 이름과 값으로 구성됩니다. "XYZ" 입력 후 [검색] → XYZ : 사전에 없는 용어입니다.

dict.get(키, 기본값) 키가 없으면 오류 대신 기본값을 돌려줍니다. 검색 앱에서 "없는 단어" 처리에 딱 맞습니다.

실행 파일(.exe) 배포 — pyinstaller

🎯 학습목표
  • 파이썬 파일(.py)을 윈도우 실행 파일(.exe)로 만드는 이유를 안다.
  • pyinstaller를 설치하고 배포 명령어를 사용할 수 있다.
  • 주요 옵션(--onefile, --windowed)의 뜻을 이해한다.
📖 개념 및 설명

내가 만든 프로그램을 다른 사람도 쓰게 하려면, 그 사람 컴퓨터에 파이썬이 없어도 실행돼야 합니다. PyInstaller는 .py 파일과 필요한 것들을 묶어 하나의 실행 파일(.exe)로 만들어 줍니다. 더블클릭만으로 실행되죠.

옵션뜻
--onefile여러 파일을 하나의 exe로 합침
--windowed실행 시 검은 콘솔 창을 숨김(GUI 프로그램용)
💡 예제 — 배포 절차

터미널(명령 프롬프트)에서 아래 순서로 실행합니다.

# 1. PyInstaller 설치 (최초 한 번)
pip install pyinstaller

# 2. 내 파이썬 파일이 있는 폴더로 이동
cd C:\pyworks\컴퓨터사전

# 3. exe로 변환 (GUI 프로그램이므로 --windowed)
pyinstaller --onefile --windowed 컴퓨터용어사전.py
실행 결과 같은 폴더에 dist 폴더가 생기고, 그 안에 컴퓨터용어사전.exe 파일이 만들어집니다. 이 exe를 더블클릭하면 파이썬 없이도 프로그램이 실행됩니다.
✏️ 실습문제

실습 9-1. 내 앱을 exe로

5장에서 만든 컴퓨터 용어 사전을 --onefile --windowed 옵션으로 exe로 만들고, dist 폴더의 exe를 더블클릭해 실행되는지 확인하세요.

미니 프로젝트: QR 코드 생성기

🎯 학습목표
  • 외부 라이브러리(qrcode)를 설치해 사용할 수 있다.
  • 텍스트·링크를 QR 코드 이미지로 저장한다.
  • 스마트폰으로 스캔해 결과를 검증한다.
📖 개념 및 설명

QR 코드는 링크나 글자를 담은 사각형 무늬입니다. 파이썬 qrcode 라이브러리를 쓰면 몇 줄로 QR 이미지를 만들 수 있어요. 표준 라이브러리가 아니라 pip로 설치가 필요합니다.

# qrcode 라이브러리 설치 (최초 한 번) — 이미지 저장용 pillow도 함께
pip install qrcode pillow
⚠️ ModuleNotFoundError: No module named 'PIL' pip install qrcode만 설치하면 실행할 때 이 오류가 납니다. PIL은 이미지 라이브러리 Pillow의 이름입니다. pip install pillow를 실행한 뒤 다시 실행하세요. (pip install "qrcode[pil]"로 한 번에 설치해도 됩니다.)
💡 예제 — qr.py 
import qrcode

data = "https://www.python.org"   # QR에 담을 링크/텍스트

img = qrcode.make(data)            # QR 이미지 생성
img.save("my_qr.png")              # 파일로 저장
print("my_qr.png 저장 완료!")

실행 결과 같은 폴더에 my_qr.png QR 이미지가 생성됩니다. 스마트폰 카메라로 스캔하면 python.org로 이동합니다.
스캔 방법 스마트폰 카메라(또는 QR 스캔 아이콘)로 코드를 비추면 링크 알림이 뜨고, 눌러서 해당 홈페이지로 이동합니다.
✏️ 실습문제

실습 10-1. 내 QR 만들기

자신의 블로그·SNS 주소나 좋아하는 사이트 링크로 QR 코드를 만들어 저장하고, 스마트폰으로 스캔해 실제로 그 사이트로 이동하는지 검증하세요.
핵심 보기
import qrcode
qrcode.make("https://내주소.com").save("me.png")

한 줄로도 만들 수 있습니다. 스캔 결과가 링크와 일치하는지 꼭 확인하세요.
