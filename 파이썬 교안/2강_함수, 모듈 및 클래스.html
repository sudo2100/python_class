함수의 개념과 정의

🎯 학습목표
  • 함수가 왜 필요한지(재사용·모듈화·가독성) 설명할 수 있다.
  • def로 함수를 정의하고 호출할 수 있다.
  • 사용자 정의 함수와 내장 함수를 구분한다.
📖 개념 및 설명

함수(Function)는 특정 작업을 수행하는 코드 블록입니다. 같은 코드를 여러 번 쓰는 대신 함수로 묶어 두면, 재사용하고 프로그램을 모듈화하며 가독성을 높일 수 있습니다.

  • 사용자 정의 함수 — 내가 직접 def로 만든 함수
  • 내장 함수 — 파이썬이 기본 제공하는 함수(print, len, sum 등)

함수는 정의한 뒤 호출해야 실행됩니다.

def 함수이름(매개변수):
    함수의 내용        # 이 블록이 함수의 몸통 (4칸 들여쓰기)
매개변수(parameter) 함수가 작업에 사용할 입력값을 받는 변수입니다. 필요 없으면 ()를 비워 둡니다.
💡 예제

인사말을 출력하는, 반환값(return)이 없는 함수입니다.

def greet(name):        # 함수 정의
    print(f"{name}님, 환영합니다!")

greet("홍길동")             # 함수 호출
greet("김파이")             # 다시 재사용
실행 결과 홍길동님, 환영합니다! 김파이님, 환영합니다!

return이 있는 함수

🎯 학습목표
  • return으로 함수의 결과값을 돌려줄 수 있다.
  • 반환값을 변수에 저장해 재사용할 수 있다.
  • 계산 결과를 돌려주는 함수를 설계할 수 있다.
📖 개념 및 설명

return은 함수가 계산한 결과값을 호출한 곳으로 돌려주는 명령입니다. print는 화면에 보여줄 뿐이지만, return한 값은 변수에 저장하거나 다른 계산에 다시 사용할 수 있습니다.

def 함수이름(매개변수):
    return 반환값     # 값을 돌려주고 함수를 끝냄
⚠️ print와 return의 차이 print는 그냥 보여주기만 하고, return은 값을 넘겨줍니다. total = add(3, 5)처럼 결과를 저장하려면 return이 필요합니다.
💡 예제 
def add(a, b):
    return a + b

result = add(3, 5)     # 반환값을 변수에 저장
print(result)          # 8

# 원의 넓이를 반환하는 함수
def circle_area(r):
    return 3.14 * r * r

print(circle_area(5))   # 78.5
실행 결과 8 78.5

매개변수로 리스트 전달

🎯 학습목표
  • 리스트를 함수의 매개변수로 넘길 수 있다.
  • 함수 안에서 다른 함수를 호출할 수 있다.
  • 리스트를 순회해 최대값과 그 위치를 찾을 수 있다.
📖 개념 및 설명

함수의 매개변수로는 숫자·문자열뿐 아니라 리스트도 넘길 수 있습니다. 여러 개의 데이터를 한꺼번에 처리할 때 유용합니다. 함수 안에서 그 리스트를 순회하거나, 가공해 새 리스트를 만들어 반환할 수 있습니다.

함수 안에서 함수 호출 함수 내부에서 다른 함수(내장 함수 포함)를 불러 쓸 수 있어, 작은 함수를 조립해 큰 기능을 만듭니다.
💡 예제

리스트의 각 요소를 2배로 만든 새 리스트를 반환합니다.

def double_all(lst):
    result = []
    for x in lst:
        result.append(x * 2)
    return result

print(double_all([1, 2, 3]))   # [2, 4, 6]
실행 결과 [2, 4, 6]
✏️ 실습문제

실습 4-1. 최대값과 위치 찾기

숫자 리스트를 받아 최대값과 그 위치(인덱스)를 함께 반환하는 함수 find_max를 만드세요. 예: [70,80,55,60,90,40] → 최대값 90, 위치 4
정답 보기
def find_max(nums):
    max_v = nums[0]        # 첫 값을 최대값으로 가정
    max_i = 0
    for i in range(1, len(nums)):
        if nums[i] > max_v:  # 더 큰 값을 만나면 갱신
            max_v = nums[i]
            max_i = i
    return max_v, max_i

v, i = find_max([70, 80, 55, 60, 90, 40])
print("최대값:", v, "/ 위치:", i)
최대값: 90 / 위치: 4

변수의 유효 범위

🎯 학습목표
  • 전역 변수와 지역 변수의 유효 범위를 구분한다.
  • 함수 안에서 만든 변수가 함수 밖에서 사라짐을 이해한다.
  • global 키워드의 역할과 주의점을 안다.
📖 개념 및 설명

변수는 어디서 만들었는지에 따라 사용할 수 있는 범위(유효 범위, scope)가 정해집니다.

구분설명
전역 변수(global)함수 밖에서 선언. 프로그램 전체에서 읽을 수 있고, 끝나면 사라진다.
지역 변수(local)함수나 블록 안에서 생성. 그 블록을 벗어나면 사라진다.

함수 안에서 전역 변수의 값을 바꾸려면 global 키워드로 “이건 전역 변수야”라고 알려야 합니다. (지역 변수에 global을 붙이면 값이 유지되는 정적 변수처럼 동작)

⚠️ global 남용 주의 전역 변수를 함수마다 바꾸면 어디서 값이 변했는지 추적하기 어렵습니다. 되도록 매개변수와 return으로 값을 주고받는 것이 좋습니다.
💡 예제 
x = 10              # 전역 변수

def show():
    y = 5          # 지역 변수 (show 안에서만 유효)
    print(x, y)     # 전역 x는 읽을 수 있음

show()
# print(y)  → 오류! y는 함수 밖에서 사라짐

count = 0
def up():
    global count   # 전역 count를 수정하겠다고 선언
    count += 1

up()
up()
print(count)         # 2
실행 결과 10 5 2

기본 매개변수와 가변 매개변수

🎯 학습목표
  • 기본값을 가진 매개변수를 정의하고 생략 호출할 수 있다.
  • 개수가 정해지지 않은 인자를 *args로 받을 수 있다.
  • 상황에 맞는 매개변수 형태를 선택할 수 있다.
📖 개념 및 설명

기본 매개변수는 매개변수에 미리 기본값을 지정해 두는 것입니다. 호출할 때 값을 생략하면 기본값이 쓰입니다.

def 함수(변수1, 변수2=1):   # 변수2를 생략하면 1이 됨
    코드블록

가변 매개변수는 인자의 개수가 정해지지 않았을 때 씁니다. 이름 앞에 *를 붙이면 넘어온 값들이 튜플로 묶여 들어옵니다.

def 함수(*변수):        # 몇 개가 오든 튜플로 받음
    코드블록
💡 예제 1 
# 기본 매개변수: exp를 생략하면 제곱(2)
def power(base, exp=2):
    return base ** exp

print(power(3))       # 9  (3의 2제곱)
print(power(2, 3))    # 8  (2의 3제곱)

# 가변 매개변수: 개수 상관없이 합계
def total(*nums):
    return sum(nums)

print(total(1, 2, 3))       # 6
print(total(1, 2, 3, 4, 5)) # 15
실행 결과 9 8 6 15
💡 예제 2 — 서울 택시 요금 계산기

서울 중형택시는 1.6km까지 기본요금 4,800원, 그 뒤로 131m마다 100원이 붙습니다. 심야에는 기본요금과 거리 요금이 함께 오릅니다. 평소에 가장 많이 쓰는 주간 요금을 기본값으로 두고, 심야일 때만 값을 넘깁니다.

시간대기본요금 (1.6km까지)거리 요금호출 방법
주간4,800원131m당 100원taxi_fare(5) — 기본값 사용
심야 22~23시, 02~04시5,800원131m당 120원taxi_fare(5, 5800, 120)
심야 23~02시6,700원131m당 140원taxi_fare(5, 6700, 140)
# 서울 중형택시 요금 계산기 (거리 요금 기준)
# 기본요금: 1.6km까지 4,800원 / 이후 131m마다 100원 (주간)
def taxi_fare(distance, base_fare=4800, unit_fare=100):
    base_km = 1.6                      # 기본 거리(km)
    unit_m = 131                       # 거리 요금이 붙는 단위(m)

    if distance <= base_km:            # 기본 거리 이내면 기본요금만
        return base_fare

    extra_m = round((distance - base_km) * 1000)   # 기본 거리를 넘은 거리(m)
    count = extra_m // unit_m                      # 131m를 몇 번 달렸나
    return base_fare + count * unit_fare

# 함수 호출 예제
print(taxi_fare(1))              # 주간 1km: 기본 거리 이내 → 4800
print(taxi_fare(5))              # 주간 5km: 기본요금 4800 + 거리 요금
print(taxi_fare(5, 5800, 120))   # 심야(22~23시, 02~04시) 5km
print(taxi_fare(5, 6700, 140))   # 심야(23~02시) 5km
실행 결과 4800 7300 8800 10200

손으로 확인해 보기 — 5km는 기본 거리 1.6km를 넘은 3,400m를 더 달렸고, 3,400 ÷ 131 = 25번(몫)이므로 주간 요금은 4,800 + 25 × 100 = 7,300원입니다. 23~02시 심야는 6,700 + 25 × 140 = 10,200원입니다.

실제 미터기와 다른 점 실제 요금에는 막히는 길에서 붙는 시간 요금(주간 30초당 100원)과 시계외 할증(서울 밖으로 나갈 때 20%)도 더해집니다. 이 예제는 거리 요금만 계산합니다. (기준: 서울시 택시요금, 2023.2.1 조정 · 2026년 현재)

내장 함수(Built-in Function)

🎯 학습목표
  • 자주 쓰는 파이썬 내장 함수를 활용할 수 있다.
  • sum·max·round·eval·list 등을 상황에 맞게 쓴다.
  • 직접 만든 함수와 내장 함수의 결과를 비교할 수 있다.
📖 개념 및 설명

내장 함수는 파이썬이 기본 제공하는, 따로 만들지 않아도 바로 쓰는 함수입니다. 자주 쓰는 것들을 알아 두면 코드가 훨씬 짧아집니다.

함수기능예 → 결과
sum(반복형)모든 요소의 합sum([1,2,3]) → 6
max(반복형)최대값 (min은 최소값)max([1,2,3]) → 3
len(반복형)요소 개수len("파이썬") → 3
round(n, 자리)반올림round(4.6) → 5
eval(문자열)문자열 수식을 계산eval("1+2") → 3
list(반복형)리스트로 변환list("py") → ['p','y']
💡 예제 
print(sum([1, 2, 3]))     # 6
print(max([1, 2, 3]))     # 3
print(round(4.6))         # 5
print(eval("1+2"))         # 3
print(list("python"))     # ['p','y','t','h','o','n']

🎯 학습목표

  • map으로 모든 요소에 연산을 적용할 수 있다.
  • filter로 조건에 맞는 요소만 뽑을 수 있다.
📖 개념 및 설명

람다 함수(Lambda)는 이름이 없는 한 줄짜리 함수입니다. def 없이 간단한 함수를 즉석에서 만들 때 씁니다. return을 쓰지 않고 표현식의 결과가 곧 반환값입니다.

lambda 매개변수: 반환할 표현식

람다는 map, filter와 자주 함께 씁니다.

함수기능
map(함수, 순서열)모든 요소에 함수를 적용한 결과
filter(함수, 순서열)함수가 참인 요소만 골라냄
list()로 감싸기 map·filter의 결과는 바로 보이지 않으므로, list()로 감싸 리스트로 변환해 확인합니다.
💡 예제 
# 람다: 제곱 함수
square = lambda x: x * x
print(square(5))        # 25

# map: 모든 요소를 2배로
print(list(map(lambda x: x * 2, [1, 2, 3])))

# filter: 짝수만 추출
print(list(filter(lambda x: x % 2 == 0, range(1, 11))))

calendar 모듈

🎯 학습목표

📖 개념 및 설명

함수 · 속성기능

🎯 학습목표

📖 개념 및 설명

객체(Object)는 “행위가 미치는 대상”으로, 책상처럼 구체적이거나 회사처럼 추상적인 데이터 단위입니다. 객체지향 프로그래밍(OOP)은 이런 객체를 먼저 만들고 객체 사이에 일어나는 일을 구현하는 방식입니다.

예를 들어 "학생이 밥을 먹는다", "학생이 버스를 탄다"처럼 객체(학생·밥·버스)와 행동(먹는다·탄다)으로 세상을 모델링합니다. C언어식 절차지향이 순서대로 처리하는 것과 대비됩니다.

특성설명
캡슐화(Encapsulation)데이터와 메서드를 하나(클래스)로 묶고, 외부의 직접 접근을 제한해 데이터를 보호
상속(Inheritance)기존 클래스의 속성·메서드를 새 클래스가 물려받아 재사용성을 높임
다형성(Polymorphism)같은 이름의 메서드가 클래스마다 다르게 동작
왜 배우나? 프로그램이 커질수록 데이터와 기능을 덩어리(객체)로 관리하면 이해·수정·재사용이 쉬워집니다.

📖 개념 및 설명

클래스(class)는 관련된 속성(변수)과 기능(메서드)을 하나로 묶는 설계도(틀)입니다. 이 설계도로 실제 만들어낸 것이 객체(인스턴스)입니다. 붕어빵 틀이 클래스, 구워진 붕어빵이 객체인 셈입니다.

class 클래스이름:
    def __init__(self):   # 생성자: 객체가 만들어질 때 자동 실행
        self.멤버변수 = 값
    def 메서드(self):
        ...

객체 = 클래스이름()      # 객체 생성
객체.멤버변수               # 점(.)으로 접근
객체.메서드()
  • __init__ — 생성자. 객체가 생성될 때 자동 호출되며 속성 초기값을 정한다. 리턴값이 없다.
  • self — 객체 자기 자신을 가리킨다. 모든 메서드의 첫 매개변수에 넣는다.

실습 16-1. 커피 자판기 클래스

class CoffeeMachine:
    def __init__(self):
        self.balance = 0            # 넣은 금액
        self.coffee_stock = 10       # 남은 커피 수
        self.coffee_price = 300      # 커피 한 잔 가격
    def insert_coin(self, money):
        self.balance += money
        print(f"{money}원을 넣었습니다.")
    def make_coffee(self):
        if self.balance < self.coffee_price:
            print("잔액이 부족합니다.")
            return
        if self.coffee_stock == 0:
            print("커피가 없습니다.")
            return
        self.balance -= self.coffee_price
        self.coffee_stock -= 1
        print("☕ 커피가 나왔습니다.")
    def return_change(self):
        print(f"잔돈 {self.balance}원을 반환합니다.")
        self.balance = 0

# 자판기 사용
machine = CoffeeMachine()
machine.insert_coin(500)
machine.make_coffee()
machine.return_change()

# 카드 클래스를 정의
class Card:
  count = 1000  # 클래스 변수 (모든 카드 객체가 공유하는 카드 번호)

  def __init__(self, owner):
    self.owner = owner
    Card.count += 1   # 카드 번호를 1 증가시킴

  def get_info(self):
    print(f"카드 소유자: {self.owner}, 카드 번호: {Card.count}")

c1 = Card("김파이")
c1.get_info()

c2 = Card("오자바")
c2.get_info()

  def __init__(self, owner):
    self.owner = owner

상속(Inheritance)

🎯 학습목표
  • 부모 클래스의 속성·메서드를 자식이 물려받는 원리를 이해한다.
  • class 자식(부모): 문법으로 상속을 구현한다.
  • super()로 부모의 생성자를 호출할 수 있다.
📖 개념 및 설명

상속은 기존 클래스(부모)의 속성·메서드를 새 클래스(자식)가 물려받는 것입니다. 공통 기능을 부모에 두고, 자식은 차이점만 추가하면 되므로 코드 중복이 줄어듭니다.

class 자식클래스(부모클래스):
    ...

super().__init__(...)는 부모의 생성자를 불러 부모가 가진 속성을 초기화합니다.

💡 예제

사람(Person)을 상속받아 사원(Employee)을 만듭니다.

class Person:
    def __init__(self, name):
        self.name = name
    def greet(self):
        print("안녕하세요,", self.name, "입니다.")

class Employee(Person):        # Person 상속
    def __init__(self, name, emp_id):
        super().__init__(name)     # 부모 생성자 호출
        self.emp_id = emp_id
    def info(self):
        print(f"사번 {self.emp_id}, 이름 {self.name}")

e = Employee("이순신", "E100")
e.greet()    # 부모에게 물려받은 메서드
e.info()     # 자식이 추가한 메서드
실행 결과 안녕하세요, 이순신 입니다. 사번 E100, 이름 이순신

다형성

🎯 학습목표
  • 다형성 — 같은 메서드가 클래스마다 다르게 동작함을 이해한다.
  • 부모 타입 하나로 여러 자식 객체를 똑같이 다룰 수 있음을 안다.
  • 다형성이 코드를 어떻게 간결하고 확장하기 쉽게 만드는지 이해한다.
📖 개념 및 설명

다형성은 같은 이름의 메서드(power)가 클래스마다 다르게 동작하는 것입니다. TV는 "📺 TV 전원", 에어컨은 "❄️ 에어컨 전원"처럼요. 덕분에 리모컨 하나로 여러 기기를 똑같이 제어할 수 있습니다.

부모 클래스(Device)에 power 메서드를 두고, 각 자식 클래스(TV·AirConditioner·Fan)가 이를 자기 방식대로 재정의합니다. 사용하는 쪽(리모컨)은 기기 종류를 신경 쓰지 않고 power()만 호출하면 됩니다.

💡 예제 
# 상속과 다형성
# 부모 클래스
class Device:
    def power(self):
        print("기기의 전원이 켜졌습니다.")

# 자식 클래스
class TV(Device):
    def power(self):
        print("📺 TV 전원이 켜졌습니다.")

class AirConditioner(Device):
    def power(self):
        print("❄️ 에어컨 전원이 켜졌습니다.")

class Fan(Device):
    def power(self):
        print("🌀 선풍기 전원이 켜졌습니다.")

# 리모컨 클래스
class RemoteControl:
    def press_power(self, device):
        device.power()

# 객체 생성
tv = TV()
aircon = AirConditioner()
fan = Fan()

remote = RemoteControl()

# 같은 버튼으로 여러 기기 제어
remote.press_power(tv)
remote.press_power(aircon)
remote.press_power(fan)
실행 결과 📺 TV 전원이 켜졌습니다. ❄️ 에어컨 전원이 켜졌습니다. 🌀 선풍기 전원이 켜졌습니다.
다형성 리모컨은 기기 종류를 몰라도 power()만 호출하면 됩니다. 새 기기를 추가해도 리모컨 코드는 그대로라, 확장이 쉬워집니다.

실습 20-1. 도형 넓이 다형성

부모 클래스 Shape에 area 메서드를 두고, Circle(반지름)과 Rectangle(가로·세로)이 각각 넓이를 계산하도록 재정의하세요. 두 객체를 리스트에 담아 넓이를 출력하세요.
정답 보기
class Shape:
    def area(self): return 0

class Circle(Shape):
    def __init__(self, r): self.r = r
    def area(self): return 3.14 * self.r ** 2

class Rectangle(Shape):
    def __init__(self, w, h): self.w = w; self.h = h
    def area(self): return self.w * self.h

for s in [Circle(5), Rectangle(4, 3)]:
    print("넓이:", s.area())
